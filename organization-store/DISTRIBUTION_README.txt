P&T AI Square — 관리자용 확장 배포 자료

이 Distribution.zip은 관리자가 서버 주소를 넣어 Setup.exe를 만드는 준비 자료입니다.
사용자에게는 생성된 Setup.exe 하나를 전달합니다. .axextension 연결 프로그램을 선택할 필요가 없습니다.
공개 Distribution에는 사내 서버 주소, 개인 KEY, MongoDB 접속 정보가 없습니다.

1. 관리자가 준비할 것
- 신뢰하는 Git 릴리즈의 Distribution.zip과 공개 SHA256을 확인하세요.
- Windows PC에서 Distribution.zip 전체를 새 폴더에 풉니다. Python 3.10 이상이 필요합니다.
- EXE 생성에 필요한 NSIS 도구와 라이선스가 동봉되어 있습니다. NSIS를 시스템에 설치하지 않습니다.
- 별도 pip 설치, 원본 저장소, .NET 컴파일러 또는 빌드 중 인터넷 다운로드가 필요하지 않습니다.
- extension-template.zip, nsis-toolchain.zip과 각각의 .sha256 파일은 수정하지 마세요.
- installer 폴더를 포함한 모든 동봉 파일을 같은 구조로 유지하세요.

2. 서버 주소를 넣은 EXE 만들기
configure_server.py를 메모장 또는 VS Code로 열어 파일 상단의 두 항목을 확인하세요.
한국어 주석이 있는 설정 부분만 수정하면 됩니다.

SERVER_URL = "https://square.company.example"  # 실제 사용자가 접속하는 웹 주소로 변경
OUTPUT_ZIP = "PNT-AI-Square-0.1.0-Setup.exe"  # 기존 변수 이름을 유지하며 출력은 EXE

파일을 저장한 뒤 압축을 푼 폴더에서 아래 한 줄만 실행하세요.

python configure_server.py

- 완성된 Setup.exe는 configure_server.py와 같은 폴더에 생성됩니다.
- 관리자가 받은 Distribution.zip만 압축을 풉니다. 사용자는 Setup.exe를 받아 실행합니다.
- SERVER_URL을 비워 두면 수정할 위치를 안내하고 파일을 만들지 않습니다.
- 서버를 실행할 때 사용하는 0.0.0.0 대신 사용자가 접속하는 주소를 입력합니다.
- HTTP 또는 HTTPS 기본 주소만 허용합니다. 사용자명, 비밀번호, 경로, 쿼리, KEY를 넣지 않습니다.
- localhost/127.0.0.1은 각 사용자 PC 자신을 뜻하므로 로컬 시험에만 사용하세요.
- HTTP도 사용할 수 있지만 KEY가 암호화되지 않은 통신으로 전달됩니다. 사용자가 앱에서 주소와 안내를 확인합니다.
- 새 설치 파일만 생성합니다. 같은 이름의 파일은 덮어쓰지 않으므로 다른 이름이나 출력 폴더를 지정하세요.
- template ZIP과 payload 파일의 SHA256, 선언된 경로·크기를 검사합니다. 동봉 NSIS ZIP도 해시·경로 검증 후 임시로 풀어 빌드하고 정리합니다.
- 빌드 중 확장 코드를 실행하거나 서버에 접속하거나 개인 프로필을 바꾸지 않습니다.
- 출력에 표시된 SHA256은 운영 배포 기록으로 보관하세요.

기존 자동화 옵션도 지원합니다.
- --server-url 및 --output 옵션은 파일 상단 설정보다 우선합니다.
- --output의 상대 경로는 명령을 실행한 폴더를 기준으로 합니다.
- 수동 가져오기용 .zip 또는 기존 .axextension 출력도 선택할 수 있습니다. 새 사용자 배포에는 기본 Setup.exe를 권장합니다.

3. 완성된 파일 등록
- 생성된 PNT-AI-Square-0.1.0-Setup.exe만 사내 웹 AX Workspace → 파일 등록에서 업로드합니다.
- 이름: P&T AI Square 확장 / 분류: 플러그인 / 버전: 0.1.0
- 설치 설명: Setup.exe 실행 → AX Workspace에서 확장 정보 확인 → 설치 → P&T AI Square 화면에서 개인 KEY 입력
- EXE는 ZIP처럼 ai-square.json으로 등록 내용을 자동 입력하지 않습니다. 위 이름·설명·분류·버전을 직접 입력하세요.
- 운영 주소를 넣은 최종 EXE와 출력 기록은 사내 배포용으로 관리하고 공개 Git에 올리지 마세요.
- 웹은 등록된 원본을 그대로 제공합니다. 업로드 후 서버 주소를 자동으로 바꾸지 않습니다.
- Distribution.zip 자체는 사용자 설치 파일로 등록하지 않습니다.

4. 사용자 설치
- 확장 가져오기를 지원하는 AX Workspace가 필요합니다. 앱 내부 업데이트로 지원 버전을 적용한 경우도 사용할 수 있습니다.
- Setup은 설치된 앱의 소유 표시를 확인한 뒤, 업데이트 완료 기록과 전체 파일 해시를 검증해 최신 앱의 설치 확인 기능을 엽니다. 처음 설치한 EXE가 구형이어도 다시 설치할 필요는 없습니다.
- 업데이트본이 없으면 확장 가져오기를 지원하는 설치 EXE를 사용합니다. 둘 다 미지원일 때만 기본 앱 업데이트를 안내합니다. 같은 버전의 예전 빌드도 있으므로 버전 숫자만으로 지원 여부를 판단하지 않습니다.
- 내려받은 Setup.exe를 실행하면 기존 AX Workspace의 설치 확인창이 열립니다.
- .axextension 파일 연결·연결 프로그램 선택·압축 해제·Python 설치가 필요 없습니다.
- AX Workspace가 없다면 먼저 공통 앱을 설치하라는 안내를 따르세요.
- 이름·버전·설치 위치·서버 주소를 확인한 뒤 앱에서 설치를 누릅니다.
- 왼쪽 P&T AI Square를 열어 개인 KEY만 입력합니다. HTTP인 경우 최초 연결 안내를 확인합니다.
- Setup의 작업 완료는 앱에 설치 확인을 요청했다는 뜻입니다. 앱에서 설치를 누르기 전에는 확장 설치가 완료되지 않습니다.
- 취소하면 확장을 설치하지 않습니다. 기존 대화와 KEY를 삭제하지 않습니다.
- 이전 확장 Setup.exe에는 이 경로 선택 기능이 없습니다. 새 Distribution에서 EXE를 다시 만든 뒤 웹에 교체 등록하세요. 기존 다운로드 파일은 자동으로 바뀌지 않습니다.
- 확장은 현재 Windows 계정에 설치됩니다. 확장 내부 Skill/MCP 설치 범위는 이후 별도로 선택합니다.
- 기존 인증된 연결이 있으면 주소와 KEY를 보존합니다. 서버를 변경하려면 연결 화면에서 직접 바꿉니다.
- 기존 ZIP 형식은 설정 → 추가 기능 → 확장 ZIP 가져오기에서도 지원합니다.

5. 앱 안에서 기능 설치
- 항목의 설치·연결 → 바로 설치하기에서 공통(내 계정) 또는 업무 목록의 업무를 선택합니다.
- 업무 목록 선택에는 이번 업무 선택 연결부가 반영된 AX Workspace도 함께 필요합니다. 구형 앱에는 업데이트 안내와 폴더 직접 선택이 제공됩니다.
- 별도 파일 다운로드를 먼저 누를 필요가 없습니다. 앱이 서버 배포 파일을 검증하고 확인한 위치에 설치합니다.
- 설치 정보가 없는 표준 Skill ZIP도 바로 설치하기에서 SKILL.md 구조를 확인한 뒤 설치 위치 선택으로 이어집니다. Skill은 파일 배치, MCP는 등록된 실행 정보에 따른 연결 설정으로 설치합니다.
- 임의 ZIP의 설치 명령은 추측해 실행하지 않습니다. 설치 정보가 없는 MCP·하네스·일반 프로그램은 등록자가 정확한 설치 정보를 제공해야 합니다.
- 저장된 플랫폼(MCP) 연결 사용은 기존 MCP의 주소·KEY를 재사용하며 MCP를 새로 실행하는 동작이 아닙니다.

6. 앱 안에서 도구 등록
- 도구 등록에서 새 도구 또는 본인이 등록한 도구의 새 버전을 선택합니다. 업로드 포함 권한의 개인 KEY가 필요합니다.
- 배포 파일(ZIP·MD·AXEXTENSION·EXE·MSI·PS1, 최대 64MiB), 웹 주소 또는 설치 명령어 안내를 등록할 수 있습니다. 선택 파일이나 명령어를 이 과정에서 실행하지 않습니다.
- 설명·조직·업무 분류·공개 범위를 확인하고 등록 내용 확인을 누릅니다. 웹에서 확인·승인 후 앱의 승인 상태 확인 → 등록 완료하기로 게시합니다.
- 파일 선택과 Noto Sans KR 글꼴 공유에는 이번 공통 AX Workspace 빌드도 함께 필요합니다. 이전 동일 버전의 EXE만으로 신규 등록 연결부를 대신할 수 없습니다.
- 등록 창의 내용은 해당 스토어 화면을 유지하는 동안 보존합니다. 파일·내용·연결 KEY가 달라지면 다시 준비하며 이미 완료한 같은 요청을 재시도해도 새 버전을 중복 등록하지 않습니다.

V3와 무결성 안내
- 새 Setup.exe는 표준 NSIS 설치 진입점입니다. 이전에 탐지된 StoreInstaller.exe는 포함하거나 실행하지 않습니다.
- Setup에 포함된 ResolveWorkspace.ps1은 한 번만 업데이트 경로·무결성을 확인하고 기존 앱의 설치 확인 기능을 호출합니다. 확장을 사용자 프로필에 설치하거나 레지스트리·연결 정보를 변경하지 않습니다. 상주 프로세스나 주기 조회를 추가하지 않습니다.
- 앱에 요청을 전달한 뒤 오류가 나도 다른 실행기로 다시 보내지 않습니다. 업데이트 파일 검증 실패·미지원 실행기·전달 결과 확인 지연을 구분해 안내합니다.
- 관리자 권한을 요청하지 않고 백신 설정이나 파일 연결을 바꾸지 않습니다.
- 이 변경은 V3 무탐지나 오탐 해제를 보장하지 않습니다. 차단되면 탐지명·파일 해시·제품/엔진 정보를 확인하고 보안 담당자 또는 보안 제품 공급자의 분석 절차를 따르세요.
- 파일 해시는 손상 확인 수단이며 게시자 전자서명 또는 안전성 판정이 아닙니다.
- 코드와 해시를 함께 변조하면 해시만으로 출처를 확인할 수 없으므로 신뢰하는 Git 릴리즈에서 받으세요.
