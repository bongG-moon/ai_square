P&T AI Square — 관리자용 확장 배포 자료

이 Distribution.zip은 관리자가 서버 주소를 지정하는 준비 자료입니다.
사용자가 설치할 파일은 아래 절차로 생성하는 Extension.zip입니다.
이 자료에는 사내 서버 주소, 개인 KEY, MongoDB 접속 정보가 없습니다.

1. 관리자가 준비할 것
- 신뢰하는 Git 릴리즈의 Distribution.zip과 공개 SHA256을 확인하세요.
- 이 Distribution.zip 전체를 새 폴더에 풉니다. Python 3.10 이상이 필요합니다.
- 별도 Python 패키지, 원본 저장소, .NET 또는 NSIS는 필요하지 않습니다.
- extension-template.zip과 .sha256은 풀거나 수정하지 않고 그대로 둡니다.

2. 서버 주소를 넣은 최종 ZIP 만들기
configure_server.py를 메모장 또는 VS Code로 열어 파일 상단의 두 항목을 확인하세요.
한국어 주석이 있는 설정 부분만 수정하면 됩니다.

SERVER_URL = "https://square.company.example"  # 실제로 접속할 웹 서버 주소로 변경
OUTPUT_ZIP = "PNT-AI-Square-0.1.0-Extension.zip"  # 기본 파일명은 그대로 사용 가능

파일을 저장한 뒤 압축을 푼 폴더에서 아래 한 줄만 실행하세요.

python configure_server.py

- 완성된 Extension.zip은 configure_server.py와 같은 폴더에 생성됩니다.
- SERVER_URL을 비워 두면 수정할 위치를 안내하고 파일을 만들지 않습니다.
- 자동화에 쓰던 --server-url 및 --output 옵션도 그대로 지원하며, 지정한 옵션이 파일 상단 설정보다 우선합니다.
- --output으로 상대 경로를 지정한 경우에는 기존처럼 명령을 실행한 폴더를 기준으로 합니다.

- 서버를 실행할 때 사용하는 0.0.0.0 대신 사용자가 접속하는 주소를 입력합니다.
- HTTP 또는 HTTPS 기본 주소만 허용합니다. 사용자명, 비밀번호, 경로, 쿼리, KEY를 넣지 않습니다.
- localhost/127.0.0.1은 각 사용자 PC 자신을 뜻하므로 로컬 시험에만 사용하세요.
- HTTP도 사용할 수 있지만 KEY가 암호화되지 않은 통신으로 전달됩니다. 사용자가 앱에서 주소와 안내를 확인합니다.
- 새 출력 ZIP만 생성합니다. 같은 이름의 파일은 덮어쓰지 않으므로 다른 이름이나 출력 폴더를 지정하세요.
- template ZIP 전체와 각 payload 파일의 SHA256, 선언된 경로·크기를 확인합니다.
- 확장 코드를 실행·변경·재빌드하지 않으며 서버 접속, 웹 등록, 개인 설정 변경도 하지 않습니다.
- 출력에 표시된 SHA256은 운영 배포 기록으로 보관하세요.

3. 완성된 파일 등록
- 생성된 PNT-AI-Square-0.1.0-Extension.zip만 사내 웹 AX Workspace → 파일 등록에서 직접 업로드합니다.
- 이름: P&T AI Square 확장 / 분류: 플러그인 / 버전: 0.1.0
- 설명: AX Workspace 설정에서 확장 ZIP을 가져와 설치하고, 개인 KEY로 연결합니다. 서버 주소는 포함되어 있습니다.
- 일반 도구 등록 화면에서는 ZIP의 ai-square.json을 읽어 설명과 설치 안내를 가져올 수 있습니다.
- 운영 주소가 포함된 최종 ZIP과 출력 기록은 사내 배포용으로 관리하고 공개 Git에 올리지 마세요.
- 웹은 등록된 원본을 그대로 전달합니다. 업로드 후 서버 주소를 자동으로 바꾸지 않습니다.

4. 사용자 설치
- 설정에 추가 기능 → 확장 ZIP 가져오기가 있는 AX Workspace가 필요합니다.
- 이전 0.23.32 설치본은 이 기능이 없을 수 있으므로 함께 제공된 새 설치본을 사용합니다.
- 최종 Extension.zip은 압축을 풀지 않고 확장 ZIP 가져오기에서 선택합니다.
- 이름·버전·설치 위치·서버 주소 확인 후 설치하고 왼쪽 P&T AI Square에서 개인 KEY만 입력합니다.
- 확장은 현재 Windows 계정에 설치됩니다. 확장 내부 Skill/MCP 설치 범위는 이후 별도로 선택합니다.
- 기존 인증된 연결이 있으면 주소와 KEY를 보존합니다. 서버를 변경하려면 연결 화면에서 직접 바꿉니다.

V3와 무결성 안내
- 이전에 탐지된 StoreInstaller.exe와 새 EXE/MSI/PowerShell 설치기를 포함하지 않습니다.
- 백신을 끄거나 예외를 추가하지 않습니다. 이 방식이 백신 무탐지나 오탐 해제를 보장하지는 않습니다.
- 파일 해시는 손상 확인 수단이며 게시자 전자서명 또는 안전성 판정이 아닙니다.
- 코드와 해시를 함께 변조하면 해시만으로 출처를 확인할 수 없으므로 신뢰하는 Git 릴리즈에서 받으세요.
