# 확장 배포 방식과 V3 검토

2026-10-25 기준 검토 기록입니다. 백신 탐지 해제나 안전 인증 결과가 아닙니다.

## 확인된 내용

- 사용자 화면에서 V3 Lite가 `StoreInstaller.exe`를 `Trojan/Win32.Gen`으로 탐지하고 삭제했습니다.
- 이전 설치 흐름은 NSIS가 임시 위치에 설치 도우미를 풀고 그 EXE로 사용자 확장 폴더에 파일을 배치했습니다. 해당 도우미는 별도 전자서명이 없었습니다.
- 기존 소스에서 파일·해시·설치 소유권 검사와 사용자 폴더 설치를 확인했습니다. 검토 범위에서 보안 제품 설정 변경·프로세스 주입·외부 실행 파일 다운로드는 발견하지 못했습니다. 이것만으로 바이너리 무해성이나 오탐을 확정할 수는 없습니다.
- 진단명의 `Gen`이나 미서명 사실만으로 V3 내부 탐지 원인을 단정하지 않습니다.

## 현재 배포 구조

`package_for_upload.py`는 기존 소스 패키징 함수만 호출합니다. 별도의 EXE 설치기를 만들거나 실행하지 않습니다. 결과 `.axextension`은 검증 가능한 ZIP 컨테이너이며, 최신 AX Workspace 설치기가 등록한 전용 파일 연결로 엽니다. **파일 더블클릭 → 기존 공통 앱에서 검증 → 설치 위치 확인 → 사용자 설치 선택** 순서입니다. 설정의 확장 ZIP 가져오기 방식도 유지합니다.

파일 형식은 백신 검사를 피하기 위한 것이 아니라 Windows에서 공통 앱으로 연결하기 위한 전용 형식입니다. `.zip` 파일 연결은 변경하지 않으며, 기존 검증된 설치 엔진을 재사용합니다. 탐지됐던 StoreInstaller.exe를 이름만 바꿔 배포하거나 실행하지 않습니다.

ZIP에는 `StoreInstaller.exe`·NSIS·PowerShell/배치 설치 명령이 없습니다. 확장 코드는 설치 후 공통 앱의 Python 환경에서 사용자 권한으로 실행됩니다. 백신을 우회하기 위해 난독화하거나 이름만 바꾸는 방식이 아닙니다. 보안 제품은 확장 Python 코드와 공통 앱을 계속 검사할 수 있습니다.

공통 앱 설치 EXE는 기존 공통 앱 설치 체계를 사용합니다. 확장 ZIP에서 도우미를 제거했다고 공통 앱 EXE의 무탐지를 보장하지 않습니다. 공식 코드서명 인증서가 제공되지 않아 서명했다고 표시하지 않습니다.

## 남은 확인

새 ZIP 및 호환 공통 앱의 **V3 수동 검사·엔진 분석 결과는 미확인**입니다. 차단이 계속되면 탐지 파일의 정확한 경로·진단명·SHA-256·제품/엔진 버전을 확보해 검토해야 합니다.
