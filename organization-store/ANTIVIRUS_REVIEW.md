# 확장 EXE 배포와 V3 검토

2026-10-25 기준 구조 검토 기록입니다. 백신 탐지 해제나 안전 인증 결과가 아닙니다.

## 확인된 문제

- 사용자 화면에서 V3 Lite가 이전 설치 도우미 `StoreInstaller.exe`를 `Trojan/Win32.Gen`으로 탐지하고 삭제했습니다.
- 이전 설치 흐름은 NSIS가 임시 위치에 해당 도우미를 풀고 도우미가 사용자 확장 폴더에 파일을 배치했습니다. 도우미에 별도 전자서명은 없었습니다.
- 이후 `.axextension` 파일을 AX Workspace에 연결하는 방식으로 바꿨지만, Windows에 연결이 등록되지 않은 환경에서는 연결 프로그램 선택 창이 표시됐습니다.
- `Gen`이라는 진단명이나 미서명 사실만으로 V3의 내부 탐지 원인을 단정할 수 없습니다. 파일 연결 실패 역시 악성코드 탐지와는 구분해서 확인해야 합니다.

## 현재 설치 구조

관리자가 Distribution의 `configure_server.py`에 서버 주소를 넣고 실행하면 **`PNT-AI-Square-0.1.0-Setup.exe`**를 생성합니다. 검증한 확장 ZIP을 표준 NSIS 실행 파일에 포함하고, 사용자가 EXE를 실행하면 설치된 AX Workspace를 명시적인 `--import-extension` 인자로 엽니다. `.axextension` 파일 연결이나 Windows 연결 프로그램 선택을 사용하지 않습니다.

**EXE 실행 → AX Workspace의 확장 검증 → 설치 정보 확인 → 사용자가 설치 → 개인 KEY 연결** 순서입니다. EXE가 확장 코드를 직접 실행하거나 사용자 프로필의 확장 파일을 직접 설치하지 않습니다. 실제 설치와 기존 연결 보존은 공통 앱의 설치 엔진이 담당합니다. Setup이 앱을 열었다는 것과 확장 설치 완료를 구분해 안내합니다.

- 이전 `StoreInstaller.exe`를 포함하거나 이름만 바꿔 다시 실행하지 않습니다.
- 새 Setup은 일반 사용자 권한을 요청하며 관리자 권한 상승, 백신 설정 변경, 백신 예외 등록, 파일 연결 변경을 수행하지 않습니다.
- 별도의 설치 도우미 EXE나 PowerShell 설치 스크립트를 실행하지 않습니다. 기존 AX Workspace의 실행 절차는 그대로 사용합니다.
- 실행 시 인터넷에서 프로그램을 내려받지 않습니다. 서버 연결은 사용자가 앱에서 연결할 때 수행합니다.
- 확장 Python 코드와 서버 주소는 EXE 안의 패키지에 들어 있습니다. 개인 KEY와 DB 접속 정보는 넣지 않습니다.
- 확장 코드는 설치 후 사용자 권한으로 실행됩니다. 공통 앱의 해시 검증을 운영체제 수준의 코드 샌드박스로 해석하면 안 됩니다.

## 관리자 빌드와 출처 확인

Distribution에는 NSIS 컴파일러 묶음과 라이선스를 동봉합니다. Python 도우미가 template·컴파일러 묶음의 해시와 경로를 검사한 뒤 NSIS를 임시로 풀어 실행합니다. 시스템에 NSIS를 설치하거나 네트워크에서 빌드 도구를 받지 않습니다. 생성된 EXE에 들어간 서버 주소는 사내 배포 정보이므로 공개 GitHub에 게시하지 않습니다.

공개 SHA-256은 배포 자료의 일치·손상 여부를 확인하는 값입니다. 코드와 해시를 함께 바꾸는 경우를 막는 전자서명은 아니므로 신뢰하는 배포 출처를 함께 확인해야 합니다. 실제 코드 서명은 조직이 소유한 인증서와 배포 절차로 별도 진행하며, 이 문서는 서명 완료를 의미하지 않습니다.

## V3 확인 범위와 남은 확인

설치 구조 변경만으로 V3 무탐지나 기존 탐지의 오탐 해제를 보장하지 않습니다. 새 EXE가 정상 설치되는지와 보안 제품이 허용하는지는 별도 확인 항목입니다. 차단되는 경우 보안 설정을 끄거나 예외로 우회하지 말고 다음 자료를 바탕으로 조직 보안 담당자 또는 AhnLab의 분석 절차를 진행합니다.

- 정확한 탐지명과 차단 시각
- 차단된 파일의 전체 이름과 SHA-256
- V3 제품명·엔진 버전
- 해당 EXE에 대응하는 소스·NSIS 스크립트·빌드 기록

사내 주소를 넣은 바이너리를 외부 분석 서비스에 제출하는 일은 별도의 정보 반출 검토 대상입니다. 현재 작업은 공개 바이너리 업로드나 보안 제품 설정 변경을 자동 수행하지 않습니다.
