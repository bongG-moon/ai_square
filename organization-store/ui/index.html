플랫폼과 한 번 연결하세요.

웹에서 받은 개인 KEY로 연결합니다.
기존 좋아요와 다운로드 기록을 그대로 사용합니다.

  1. 01플랫폼 주소 입력
  2. 02웹의 연결 KEY 입력
  3. 03기능을 찾아 다운로드·설치

새 KEY를 발급할 필요는 없습니다. 기존에 발급받은 유효한 KEY를 사용하세요.

사용 중인 플랫폼의 기본 주소를 입력하세요.

현재 Windows 계정에 암호화해 보관합니다. 대화나 로그에는 남기지 않습니다.

기능을 불러오는 중입니다.

조회·좋아요·다운로드는 웹의 기록과 연결됩니다. 파일 다운로드와 실제 설치 상태는 구분해서 표시합니다.
