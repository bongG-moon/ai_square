# 샘플 데이터

`catalog.json`은 `PTAI_DATA_MODE = 'dummy'`에서만 읽는 가짜 자료입니다.
실제 MongoDB로 복사하거나 초기 자료로 삽입하지 않습니다.

- 10개 도구, 조직·업무 분류, 사용자 검색, 기능 요청 예시를 담습니다.
- 화면용 버전·좋아요·다운로드 수는 `dummy_api.py`에서 구성합니다. 실제 사용 통계가 아닙니다.
- `PTAI_MOCK_USER`가 처음 3개 도구의 등록자로 표시됩니다.
- 읽기 전용으로, 실제 파일이나 회사 자료를 넣지 마세요.
- 내용을 바꾸면 서버를 재시작하세요. 실제 운영은 `PTAI_DATA_MODE = 'mongodb'`입니다.
