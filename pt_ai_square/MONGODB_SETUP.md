# MongoDB 설정 — v3.1

URI가 없거나 비어 있으면 `demo/catalog.json`으로 읽기 전용 화면을 제공합니다. 로그인 없이 가상 자료를 볼 수 있지만 저장·업로드·다운로드는 차단됩니다. 실제 서비스 기능을 시험하려면 아래 설정이 필요합니다. 설정된 DB의 장애 때에는 더미 모드로 전환하지 않습니다.

현재는 좋아요·다운로드뿐 아니라 기능 목록, 버전, 사용자, 권한, 요청, 피드백, 알림, 관리자, 운영 이력까지 모두 MongoDB에 저장합니다. SQLite 대체 모드는 없습니다.

`runtime_config.py`에 `MONGODB_URI`, `MONGODB_DATABASE`, `PTAI_ADMIN_IDS` 등 필요한 값을 직접 입력합니다. 실제 프로세스 환경변수가 있으면 우선 적용됩니다. `.env`는 읽지 않습니다.

[실행 순서와 사용자별 버튼 안내](GUIDE_V3.md)를 확인하세요. 이전 v2의 SQLite 대기열 설명은 현재 구현에 적용되지 않습니다.
