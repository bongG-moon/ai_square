# P&T AI SQUARE 사용자·등록자 가이드

동료가 만든 도구를 찾아 사용하고, 내가 만든 노하우를 공유하는 공간입니다. 이 가이드는 사이트에서 누를 버튼과 준비할 자료를 설명합니다.

## 필요한 도구 찾기

홈 검색창에 도구 이름이나 업무를 입력하고 검색 버튼을 누릅니다. ‘주간 보고’나 ‘장비 점검’을 검색하면 둘러보기에서 이름·소개·관련 업무 태그가 맞는 도구를 보여줍니다. 사용 프로그램, 조직, 업무, 공유 유형으로 좁힐 수 있습니다.

둘러보기는 한 페이지에 12개를 표시합니다. 결과가 더 있으면 아래 이전·다음 화살표로 이동합니다. 실시간 TOP 10은 최근 좋아요와 다운로드를 반영하며 1–5위와 6–10위를 자동으로 보여줍니다.

## 상세 내용과 파일 사용하기

카드를 누르고 설치·연결 탭을 확인합니다. 파일 다운로드를 누르면 등록된 원본 파일을 받습니다. URL 연결형은 안내된 주소와 연결 방법을 확인합니다.

- EXE·MSI: 완성된 설치 프로그램입니다. 등록자가 적은 설치 순서와 설치 후 확인 방법을 따릅니다.
- ZIP: 여러 파일을 묶은 패키지입니다. 압축을 푼 뒤 안내한 위치에 놓거나 실행합니다.
- PS1: PowerShell 스크립트입니다. 사내 실행 정책과 등록자의 사용 방법을 확인합니다.
- URL: 웹 서비스나 MCP 서버 주소입니다. 사용하는 프로그램의 연결 설정에 안내된 방식으로 추가합니다.

다운로드만으로 Claude나 ChatGPT에 자동 설치되지는 않습니다. 웹은 ZIP을 EXE로 변환하지 않습니다.

## 조회 권한 신청

승인형 도구도 목록에 표시됩니다. 카드를 누르면 조회 권한이 필요하다는 팝업이 나옵니다. 사용 목적을 적고 신청하기를 누릅니다. 승인 결과는 오른쪽 위 종 모양 알림에서 확인합니다. 등록자와 관리자는 바로 조회할 수 있습니다. 플랫폼 조회 승인과 실제 업무 데이터 접근 권한은 별개입니다.

## 공유 자료 준비

상단 파일 배포 Skill에서 ZIP을 받고 AI 도구에 지침으로 제공합니다. 예: ‘이 프로젝트를 공유할 수 있도록 파일과 사용 설명을 정리해줘. 개인 경로와 비밀번호는 제외해줘.’ 결과를 직접 확인한 뒤 등록합니다.

| 공유 유형 | 예시 | 준비할 자료 |
|---|---|---|
| MCP/Tool | 문서 검색 MCP, 데이터 처리 프로그램 | 연결 URL 또는 실행·설치 파일 |
| Skill | 주간 보고 지침, Python 처리 코드 | SKILL.md, scripts, 참고 자료를 묶은 ZIP |
| 플러그인/하네스 | Claude 플러그인, 작업 흐름 실행 환경 | 해당 프로그램용 배포 패키지와 연결 안내 |

## 도구 등록 1단계 — 기본 정보

오른쪽 위 도구 등록을 누릅니다. 이름, 소개, 관련 업무 태그를 적고 프로그램·유형·조직·업무를 선택합니다. 관련 업무에는 ‘불량 분석, 수율 검토’처럼 동료가 검색할 말을 적습니다.

조회 권한 스위치를 끄면 사내 사용자가 바로 상세를 볼 수 있습니다. 켜면 등록자·관리자에게 승인받은 사용자만 상세·파일·피드백을 봅니다. 목록에는 두 경우 모두 표시됩니다. 다음을 누릅니다.

## 도구 등록 2단계 — 파일·연결

파일 등록을 선택하고 파일을 업로드 영역에 끌어다 놓거나 파일 선택을 누릅니다. ZIP·EXE·MSI·PS1 중 하나를 선택합니다. 파일명과 크기가 표시되며, 잘못 골랐다면 파일 옆 X로 취소할 수 있습니다. 실제 전송은 마지막 게시 버튼을 누를 때 진행됩니다.

URL 연결을 선택했다면 HTTPS 주소를 입력합니다. 사용 환경과 설치·연결 방법도 적습니다. 설치·연결 방법은 다운로드 이후 사용자가 무엇을 해야 하는지 알려주는 설명입니다.

- EXE 예시: ‘Setup.exe 실행 후 Claude를 다시 시작하세요. 도구 목록에 장비 검색이 표시되는지 확인하세요.’
- Skill 예시: ‘ZIP을 풀고 회사에서 사용하는 Skills 위치에 폴더를 추가하세요. 주간 보고 작성을 요청하세요.’
- MCP 예시: ‘프로그램의 MCP 연결 설정에 안내한 URL과 사내 인증 방법을 입력하세요.’

## 도구 등록 3단계 — 확인·게시

설명·권한·파일을 확인하고 게시를 누릅니다. 서버가 크기와 기본 형식을 검사하고 v1처럼 배포 번호를 발급합니다. 원본 형식으로 배포하며 자동 EXE 변환은 하지 않습니다. 기본 파일 검사에 악성코드 검사나 기능 실행 검증은 포함되지 않습니다.

## 수정·새 버전·롤백

등록 관리에는 내가 등록한 기능만 나옵니다. 수정에서 설명과 분류를 바꿉니다. 파일을 바꾸려면 버전 → 새 버전 등록을 누릅니다. v2, v3 번호는 자동 발급됩니다. 등록자·관리자만 수정·삭제·버전 변경을 할 수 있습니다.

배포 문제가 있으면 버전에서 이전 버전의 이 버전으로 복구를 누릅니다. 서버의 배포 버전이 바뀌며 사용자 PC 파일을 자동으로 덮어쓰지는 않습니다. 현재 배포와 복구용 보호 버전은 삭제할 수 없습니다. 권한 관리에서는 신청 승인·반려·권한 회수·직접 사용자 추가를 할 수 있습니다.

## 피드백과 개인 알림

도구 상세의 의견 탭에서 오류나 개선 의견을 남깁니다. 등록자·관리자가 답변과 처리 상태를 남길 수 있습니다. 업데이트 알림 받기를 누르면 새 버전 소식을 받을 수 있습니다. 종 모양에 답변·권한 결과·버전 소식이 모입니다.

## 새 기능 요청과 첨부 자료

기능 요청 → 새 기능 요청을 누릅니다. 불편한 점과 원하는 결과를 적고 관련 업무를 선택합니다. 이미지나 예시 파일을 끌어다 놓거나 파일 선택을 누릅니다. 최대 5개, 파일당 20MB이며 PNG·JPG·WEBP·PDF·TXT·CSV·XLSX·DOCX·ZIP을 지원합니다. 파일 옆 X로 게시 전 선택을 취소합니다.

등록 후 상세 화면의 첨부 자료에서 다운로드할 수 있습니다. 요청과 자료는 사이트 사용자가 함께 볼 수 있으므로 공유 가능한 자료만 첨부하세요.

개발자는 제가 구현할게요를 눌러 담당자가 되고 답변과 개발 중 상태를 남깁니다. 완성 후 구현 완료를 선택하고 등록된 기능을 연결합니다. 요청자는 개인 알림으로 진행 상황을 확인합니다.

## 배포 Skill로 준비한 ZIP 등록하기

1. 상단 **파일 배포 Skill → Skill ZIP 다운로드**를 누르고 압축을 풉니다.
2. AI 도구에 Skill을 제공하고 “이 프로젝트를 ai-square.json과 설치 안내가 포함된 P&T AI SQUARE 배포 ZIP으로 준비해줘”라고 요청합니다. 만들어진 코드와 설치 안내를 확인합니다.
3. 웹의 **도구 등록 → ZIP에서 불러오기**를 누르고 결과 ZIP을 선택합니다. 파일은 검사하기 위해 임시 전송되고 검사 후 서버 임시 파일은 삭제됩니다. 아직 게시되지는 않습니다.
4. **배포 정보 확인 완료**를 확인합니다. 빈 등록 양식에는 이름·소개·프로그램·유형·관련 업무 태그·설치 안내가 자동 입력됩니다. 이미 작성한 내용이나 새 버전 등록은 **ZIP 정보를 입력란에 적용**을 눌러 가져옵니다.
5. 조직·업무 분야·담당자·조회 권한은 직접 선택합니다. 이름·소개·안내는 검토 후 수정할 수 있으며 프로그램·유형은 ZIP 선언과 일치해야 합니다.
6. **다음 → 파일·연결 → 확인·게시**를 진행합니다. 서버가 실제 올라온 파일을 다시 검사하고 배포 번호를 발급합니다.
7. 게시 완료 화면에서 **배포 정보 JSON 받기**를 누르면 도구 ID·배포 번호·버전 확인 주소가 연결된 파일을 받습니다. 나중에도 **상세 → 사용 시작 / 버전**에서 받을 수 있습니다.

예를 들어 장비 조회 MCP ZIP이 scripts/main.py를 시작 파일로 선언했는데 해당 파일이 빠져 있으면 “필수 파일이 없습니다: scripts/main.py”라고 표시합니다. AI에게 누락된 파일을 포함해 다시 준비하도록 요청하고 새 ZIP을 선택하세요. 파일 검사는 코드의 정상 작동이나 보안을 보증하지 않습니다.

파일은 원본 그대로 배포합니다. ZIP을 EXE로 바꾸거나 설치 명령을 서버에서 실행하지 않습니다. 별도의 배포 정보 JSON은 설치 프로그램이 아니며, 실제 설치 후 어떤 배포를 사용 중인지 기록하고 버전 확인을 연결할 때 참고하는 정보입니다. 버전 확인 코드는 제작자가 실행 지점에 연결해야 합니다.

기존 ZIP·EXE·MSI·PS1도 등록할 수 있습니다. ai-square.json이 없으면 **일반 파일 등록**으로 표시되고 직접 입력합니다. ai-square.json을 사용하는 도구는 새 버전에도 같은 packageId를 유지하세요. 원격 MCP URL은 기존 URL 등록 방식으로 안내합니다. 샘플 데이터 모드는 조회 전용이므로 실제 등록과 검사는 실제 데이터 모드에서 진행합니다.
