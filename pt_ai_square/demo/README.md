# 별도로 관리하는 더미 데이터

`catalog.json`은 화면 체험 전용 가상 도구·사용자·업무 분류입니다. 실제 등록 자료나 개인정보가 아닙니다.

MongoDB URI가 비어 있을 때만 이 파일을 읽습니다. 수정한 뒤 서버를 재시작하면 체험 화면에 반영됩니다. MongoDB에 자동으로 가져오지 않으며, 클릭으로 이 파일을 변경하지 않습니다. 좋아요·업로드·수정·승인·다운로드는 저장되지 않도록 차단합니다. 실제 서비스를 사용하려면 `runtime_config.py`의 `MONGODB_URI`를 설정하세요.

이미 설정된 MongoDB의 장애 때에는 더미 화면으로 전환하지 않습니다.
