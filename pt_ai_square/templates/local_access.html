1. 로컬 연동 준비

Python 3.11 이상이 필요합니다. 압축을 풀면 다운로드용 Skill과 실행 프로그램이 들어 있습니다.

다운로드용 Skill 받기 배포·자동 등록 Skill 받기

배포·자동 등록 Skill에는 파일 준비와 게시 프로그램이 함께 들어 있습니다. 공개·조회 승인 여부를 확인한 뒤 새 도구 또는 새 버전으로 게시합니다. EXE 자동 변환 기능은 아닙니다.

로컬 SSO 미사용 시험에서는 인증키 없이 이용할 수 있습니다. 사내 SSO 환경에서는 아래 인증키를 사용하세요.

2. 내 사번의 API 인증키

조회·다운로드 전용 또는 업로드 포함 권한을 선택하세요. 업로드 포함 키는 새 도구 등록과 본인이 관리할 수 있는 도구의 새 버전 게시를 지원합니다. 삭제·권한 변경은 지원하지 않습니다.

아래 키는 지금 한 번만 표시됩니다. 대화창에 붙여넣지 말고 로컬 프로그램의 인증키 입력란에 입력하세요.

이용 건수를 확인하고 있습니다.

업로드는 게시된 버전마다 1건입니다. 다운로드는 웹·API를 합쳐 같은 사번·도구당 최초 1회만 반영하며, 반복 수신과 업데이트는 제외합니다. 아래에는 제외된 전송 이력도 남습니다.

      3. 검색하고 받기

      압축을 푼 폴더에서 아래 명령을 실행하세요. 주소는 실제 접속한 웹 주소로 설정합니다.

      python scripts/square_client.py configure --url {{ request.url_root.rstrip('/') }}
python scripts/square_client.py search "회의록"
python scripts/square_client.py download 1 --output ./downloads

      마지막 명령의 1은 검색 결과의 도구 ID로 바꾸세요. 파일의 SHA-256과 크기를 확인해 저장하며, 압축 해제·설치·실행은 하지 않습니다.

      파일 준비와 자동 게시까지 필요하면 배포·자동 등록 Skill을 사용하세요. 인증키가 없으면 프로그램이 발급 화면을 엽니다. 기존 키 원문은 다시 볼 수 없으므로 분실 시 새로 발급하세요.
