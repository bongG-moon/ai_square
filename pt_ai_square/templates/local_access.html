ZIP을 풀고 Connect.cmd를 실행하세요. 서버 주소와 다운로드 위치가 자동으로 표시됩니다. 개인 KEY를 입력하고 연결하기를 누르면 본인 이름·부서가 표시됩니다. HTTP 사이트는 연결 안내를 한 번 확인합니다.

파일은 내 사용자 폴더의 AI_SQUARE\downloads 아래 서버·도구·버전별로 저장됩니다. 실제 설치 시에는 프로젝트 또는 내 계정 범위를 선택합니다. 다른 폴더의 자료를 등록할 때는 AI에 원본 폴더 선택 창을 열어 달라고 요청하세요.

처음 MCP를 설치하는 경우

Python 3.11 이상이 필요합니다. 연결 창에는 KEY만 입력합니다. Claude Code 등에 MCP를 처음 등록하는 경우 아래 명령으로 실행 환경을 준비한 뒤 ZIP 안 README의 MCP 등록 순서를 따르세요. 이미 MCP를 등록했다면 실행 경로는 유지할 수 있습니다.

python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run_mcp.py connect

연결 창을 사용할 수 없는 환경에서는 python run_mcp.py setup을 실행하세요. 이 사이트에서 받은 ZIP은 주소를 포함하므로 서버 주소·작업 폴더를 입력하지 않습니다. KEY는 숨김 입력으로 받습니다.

Windows에서는 KEY를 사용자 계정으로 암호화해 보관합니다. KEY는 채팅에 붙여넣지 마세요. Claude의 Connected 표시는 MCP 실행 상태이며 실제 계정 연결은 위 연결 창 또는 connection_status로 확인합니다. KEY 재발급 후에는 Connect.cmd에서 새 KEY로 다시 연결하세요.

Python 3.11 이상이 필요합니다. 필요한 Skill을 받아 압축을 풀고 사용하는 AI에 등록하세요.

다운로드용 Skill 받기 ↗도구 검색 · 파일 받기 · 최신 버전 확인배포·자동 등록 Skill 받기 ↗파일 준비 · 신규 등록 · 새 버전 게시

배포 Skill은 웹에서 파일·내용·공개 범위를 승인한 뒤 AI 대화에서 게시를 이어갑니다. EXE 자동 변환은 하지 않습니다. MCP의 자동 설치는 지원하는 설치 정보가 있는 항목에 한합니다.

연결 명령어 보기

압축을 푼 Skill 폴더에서 아래 명령을 실행하세요. 마지막 명령의 1은 검색 결과의 도구 ID로 바꿉니다.

python scripts/square_client.py configure --url {{ request.url_root.rstrip('/') }}{% if request.scheme == 'http' %} --allow-http{% endif %}
python scripts/square_client.py --authenticate search "회의록"
python scripts/square_client.py --authenticate download 1 --output ./downloads

KEY가 없으면 발급 화면으로 안내합니다. 재발급 후에는 연결한 프로그램들의 KEY도 새 값으로 바꿔주세요. 로컬 mock 시험은 인증키 없이도 같은 PC에서 사용할 수 있습니다.

로컬 MCP와 Skill은 위에서 연결할 수 있습니다. CUBE 메신저·별도 앱 연결은 해당 연동이 추가된 뒤 이용할 수 있습니다.
