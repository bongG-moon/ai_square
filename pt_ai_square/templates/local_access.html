      로컬 MCP 받기이 사이트 주소가 포함된 ZIP 파일입니다.
      1. ZIP을 받고 압축 풀기

        위 버튼으로 받은 파일의 압축을 풀고, 안에 있는 pt-square-mcp 폴더를 여세요.

      2. 내 연결 KEY 준비하기

        이 페이지의 ‘내 연결 KEY’에서 발급합니다. 이미 보관한 유효한 KEY가 있다면 그대로 사용하세요.

      3. Connect.cmd를 열고 KEY 연결하기

        Connect.cmd를 더블클릭한 뒤 가려진 입력란에 KEY를 넣고 ‘연결하기’를 누르세요. 서버 주소와 다운로드 폴더는 자동 설정됩니다. HTTP라면 연결 안내를 확인하세요.

      4. 처음 한 번, AI에 MCP 등록하기

        아래 설치 안내서의 ‘AI에 MCP 등록’ 순서대로 진행하세요. 이미 등록했다면 건너뜁니다. Connect.cmd는 계정을 연결하며, AI에 MCP를 등록하는 작업은 별도입니다.

      5. 연결을 확인하고 사용하기

        AI 프로그램을 다시 열고 ‘AI SQUARE 연결 상태 확인해줘’라고 요청하세요. 본인 정보가 확인되면 ‘회의록 도구 찾아줘’처럼 사용할 수 있습니다.
