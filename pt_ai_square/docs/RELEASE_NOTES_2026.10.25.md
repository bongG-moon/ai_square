# P&T AI Square — AX Workspace 선택 확장 연동

2026-10-25 · 확장 버전 0.1.0

## 최신 웹 배포 정책

AX Workspace 탭은 관리자가 완성된 프로그램을 직접 등록하는 자료실입니다. 웹에 특정 확장 소개나 고정 설치 EXE를 내장하지 않습니다. 관리자는 **AX Workspace → 파일 등록**에서 완성된 파일과 설명·분류·배포 버전을 등록하고, 사용자는 해당 카드를 찾아 다운로드합니다. KEY 페이지의 기본 안내는 AX Workspace 탭으로 이동하는 방식이며, 기존 로컬 MCP와 다운로드용 Skill은 접힌 보조 안내에서 제공합니다.

등록된 파일은 원본 그대로 전달합니다. 프로그램이 설치 EXE와 `connection.json`을 함께 요구하면 **배포자가** 완성된 ZIP에 넣어 등록해야 합니다. 웹이 EXE를 추가하거나 서버 주소를 주입하지 않습니다. `organization-store/` 개발 소스는 보존하며 프로그램이 완성되면 관리자가 원하는 분류로 등록합니다.

P&T AI Square의 최신 선택 확장은 **EXE가 없는 별도 확장 ZIP**으로 준비합니다. 배포자가 서버 주소를 지정해 패키징한 파일을 AX Workspace 자료실에 직접 등록하고, 사용자는 ZIP 가져오기를 지원하는 공통 앱의 **설정 → 추가 기능 → 확장 ZIP 가져오기**로 설치한 뒤 개인 KEY를 입력합니다. 예전 0.23.32에는 가져오기 메뉴가 없을 수 있으므로 버전 숫자만으로 호환성을 판단하지 않습니다. 사내 주소를 넣은 배포 ZIP은 공개 Git에 올리지 않습니다. 구형 `StoreInstaller.exe`를 포함하지 않는 것과 V3의 안전 판정은 별개이며 실제 사내 환경 확인이 필요합니다.

기존 `/local-access/workspace-extension.zip`과 `/static/guides/ax-workspace-extension-setup.exe` 링크는 로그인 후 AX Workspace 탭(`/?view=ax`)으로 이동합니다. 최신 웹 소스에는 해당 고정 EXE가 포함되지 않습니다. 코드 교체 시 기존 `runtime_config.py`, MongoDB 데이터와 업로드 저장소는 유지합니다. 이미 등록한 AX 자료와 사용자의 설치 프로그램을 자동 교체하지 않습니다.

## 운영 서버 설정

- 공개 Git에 올리는 소스·배포 파일에는 사내 서버 주소와 개인 KEY, DB 접속 정보를 넣지 않습니다. 웹 운영 설정은 Git에 포함하지 않는 `runtime_config.py` 또는 서버 환경변수로 관리합니다. 사내 배포용 확장 ZIP에는 지정한 서버 주소만 포함할 수 있으며, 개인 KEY와 DB 접속 정보는 넣지 않습니다.
- 로컬 MCP 다운로드에 리버스 프록시의 내부 주소가 들어가면 `PTAI_PUBLIC_URL`에 사용자가 접속하는 웹 기본 주소를 지정합니다. 서버 실행 주소 `0.0.0.0`을 넣지 않습니다. 이 설정은 AX Workspace에 등록한 파일을 변경하지 않으며, 기존 DB 접속 설정과 실행 방식도 바꾸지 않습니다.
- 직원 사진은 선택 설정인 `PTAI_EMPLOYEE_PHOTO_BASE_URL`에 사진 폴더의 HTTP(S) 주소를 지정하면 제공합니다. 서버가 그 주소에 사번과 `.jpg`를 붙여 조회합니다. 미설정 또는 사진 조회 실패 시 이름 첫 글자를 표시하며 나머지 기능은 유지됩니다. 실제 주소는 운영 담당자가 설정합니다.

로컬 MCP의 기존 서버 주소 자동 설정과 KEY 재연결 기능은 유지합니다. AX 프로그램은 관리자가 등록한 설치 안내에 따라 연결합니다. 개인 KEY·쿠키·MongoDB 접속 정보를 배포 ZIP에 포함하지 않습니다.

## 목록 반응 속도와 댓글 알림 개선

- 목록 생성 시 도구마다 반복하던 분류·권한·구독·작성자 조회를 요청 단위 일괄 조회로 줄였습니다. 부서 권한은 DB에 저장된 실제 SSO 부서 정보를 기준으로 판단하고, 사용자 간 캐시를 공유하지 않습니다.
- 홈·둘러보기·AX 화면에서 보이지 않는 목록을 반복 생성하지 않으며, 이미 그린 아이콘과 변경 없는 프로필 사진을 유지합니다.
- 다른 사람이 남긴 댓글은 실제 도구 등록자에게 알립니다. 작성자의 자동 구독 오류나 다른 수신자 오류가 나머지 알림 전달을 막지 않으며, 실패한 후속 작업은 중복 없이 다시 처리합니다.
- 알림 창은 조회 중에도 바로 열리고, 읽음 처리 후 늦게 도착한 응답이 예전 알림 숫자를 복구하지 않도록 했습니다. 알림을 누르면 도구의 의견 탭으로 이동합니다.
- 격리 MongoDB의 도구 100개·댓글 400개·답변 800개에서 일반 사용자 목록 핸들러 읽기 명령은 1,808회에서 11회, 중앙 처리 시간은 약 2,114ms에서 21ms로 감소했습니다. 인증·네트워크·브라우저 시간은 제외한 시험 결과이며 운영 전체 로딩 속도를 보장하는 수치는 아닙니다.
- 관련 서버 회귀 시험, 화면 비동기 시험, 실제 브라우저의 알림→의견 이동을 검증했습니다. 운영 설정·업로드·DB 초기화는 필요하지 않습니다.

## 이전 2026-10-25 배포 기록

아래는 처음 공개한 확장 0.1.0의 배포 파일과 동작 기록입니다. 최신 웹의 내장 다운로드 방식을 설명하는 항목이 아닙니다.

- **ai-square-2026.10.25-source.zip**: 당시 플랫폼과 확장 소스이며 고정 EXE `static/guides/ax-workspace-extension-setup.exe`를 포함했습니다. 최신 코드 교체에 이 예전 EXE를 추가할 필요는 없습니다.
- **PNT-AI-Square-Extension-0.1.0-Setup.exe**: 당시 범용 확장 설치 파일입니다. 주소 파일 없이 설치하면 서버 주소를 직접 입력하는 방식이었습니다.
- **SHA256SUMS.txt**: 당시 두 파일의 SHA-256 기록입니다.

당시 웹은 설치 EXE와 서버 주소를 담은 `connection.json`을 ZIP으로 조립했습니다. 이 전용 경로는 최신 웹에서 AX Workspace 탭으로의 이동으로 대체됐습니다.

공통 AX Workspace 본체는 별도 제품입니다. 당시 소스는 [workspace-local-0.23.32-source.zip](https://github.com/bongG-moon/workspace_local/releases/download/v0.23.32/workspace-local-0.23.32-source.zip), 설치 파일은 [AX Workspace 0.23.32 설치 파일](https://github.com/bongG-moon/workspace_local/releases/download/v0.23.32/AX-Workspace-0.23.32-Setup.exe)로 제공했습니다. 동일한 버전 숫자의 이전 배포본에는 확장 연결부가 없을 수 있으므로 실제 연결부 지원 여부를 확인해야 합니다.

## 이전 구현의 검증 범위

공통 앱의 확장 연결, 미설치 상태, 기존 업무·초안 보존, 당시 웹 다운로드, 설치 도우미, 패키지 worker 인증, 기존 연결 보존, HTTP 확인과 긴 Windows 경로를 로컬 격리 환경에서 검증했습니다. 최신 자료실 정책 변경의 검증은 해당 변경 결과를 따르며, 이 과거 결과로 대신하지 않습니다. 사내 서버·개인 KEY·VDI 정책은 실제 운영 환경에서 확인해야 합니다.

이 릴리즈 게시가 사내 GitLab이나 웹 서버를 자동으로 갱신하지는 않습니다. 확장을 설치하지 않은 사용자에게 조직용 화면이나 백그라운드 작업이 추가되지 않습니다.
