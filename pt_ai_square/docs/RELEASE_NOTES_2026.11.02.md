# 2026-11-02 사용 경험 개선

등록 중 창을 닫거나 통신이 끊겨도 작성한 내용을 이어 쓸 수 있도록 보완했습니다. 웹과 MCP, 확장 프로그램은 같은 검색 기준을 사용하며, 확장에서는 설치 가능 여부와 목록 조회 실패를 구분해 안내합니다.

## 변경 내용

- 등록 초안을 사용자와 도구별로 보관합니다. 새로고침 후에는 입력 내용을 복원하고 파일 재선택을 안내합니다. 구형 클라이언트의 초안도 이전합니다.
- 게시 결과가 불확실할 때 같은 요청 번호로 결과를 확인하거나 재시도합니다. 늦은 응답이 새 입력이나 다른 모달을 덮지 않도록 보호합니다.
- 웹 문장 검색을 공통 검색 API에 연결하고 조직별 결과 수, 업무 분류, 등록자 이름의 띄어쓰기 처리를 맞췄습니다. 상세 권한은 기존 API에서 다시 확인합니다.
- 기존 바로 설치 기능을 유지하면서, 구조 확인이 필요한 ZIP에는 **설치 가능 여부 확인**을 표시합니다.
- 확장 목록의 조회 오류와 설치 결과를 분리합니다. 페이지 추가 조회가 실패해도 기존 목록을 유지하고, 이전 검색이나 연결의 늦은 응답을 무시합니다.
- 설치 정보에 기록된 배포 출처, 도구 번호, 플랫폼 배포 번호와 SHA-256을 표시합니다. 기존 설치 경로와 실제 Skill 이름 조회도 유지합니다.
- 사용자 가이드와 관리자용 확장 배포 ZIP을 갱신했습니다. 기존 인기 영역 동작은 변경하지 않았습니다.

## 검증

| 대상 | 결과 |
| --- | --- |
| 웹 Node 회귀 | 325개 통과 |
| 검색과 게시 API, 격리된 MongoDB | 114개 통과 |
| 확장 worker, ZIP 설치, 설치 기록 | 131개 통과 |
| 확장 설치 안내, 목록 상태, 출처 UI | 14개 통과 |
| 배포 패키지와 가이드 생성 | 40개 통과 |

배포 ZIP의 내부 파일 해시, 원본 소스 일치, 중첩 ZIP 무결성과 개인 KEY 포함 여부를 검사했습니다. 테스트에서 생성한 설치 EXE는 실행하지 않았습니다. 이번 통합본은 자동 회귀 검사와 코드 검토로 확인했으며 사내 운영 서버, 실제 SSO 계정과 사용자 PC 설치 검증을 대신하지 않습니다.

## 배포 파일

- 확장 준비 자료: `organization-store/dist/PNT-AI-Square-0.1.0-Distribution.zip`
- 체크섬: `organization-store/dist/SHA256SUMS.txt`
- 사용자 가이드: `pt_ai_square/static/guides/pt-ai-square-user-guide.html`

Distribution ZIP은 서버 주소가 없는 관리자용 준비 자료입니다. 사용자에게 전달할 설치 파일은 `organization-store/README.md`의 절차로 생성합니다. 웹 반영만으로 기존 사용자에게 설치된 확장 프로그램이 자동 교체되지는 않습니다.
