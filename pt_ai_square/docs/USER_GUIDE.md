# P&T AI SQUARE 사용자·등록자 가이드

동료가 만든 도구를 찾아 사용하고, 내가 만든 노하우를 공유하는 공간입니다. 이 가이드는 사이트에서 누를 버튼과 준비할 자료를 설명합니다.

## 필요한 도구 찾기

홈 검색창에 도구 이름이나 업무를 입력하고 검색 버튼을 누릅니다. ‘주간 보고’나 ‘장비 점검’을 검색하면 둘러보기에서 이름·소개·관련 업무 태그가 맞는 도구를 보여줍니다. 사용 프로그램, 조직, 업무, 공유 유형으로 좁힐 수 있습니다.

둘러보기는 한 페이지에 12개를 표시합니다. 결과가 더 있으면 아래 이전·다음 화살표로 이동합니다. 각 카드에는 어떤 자료로 무엇을 하는지 소개가 1~2줄로 표시됩니다. 긴 소개는 카드를 눌러 상세 화면에서 확인합니다.

홈의 **동료들이 많이 찾는 도구** 영역에서 **실시간 / 누적 / 함께 만드는 사람들**을 눌러 원하는 순위를 선택합니다. 실시간은 최근 7일, 누적은 전체 기간의 도구 인기도입니다. 도구 순위는 좋아요 2점·다운로드 1점이며 1–5위와 6–10위를 5초마다 자동으로 보여줍니다.

## 함께 만드는 사람들 — 함께 쓰는 도구를 만든 사람들

홈 순위 영역에서 **함께 만드는 사람들**을 누르면 전체 기간의 공유 기여도 TOP 10과 내 순위를 확인할 수 있습니다. 순위 제목 옆 정보 아이콘을 누르면 집계 기준을 확인합니다.

각 행은 **부서 → 이름 → 사진** 순서로 표시합니다. 긴 부서명은 마우스를 올리면 전체 이름을 확인할 수 있습니다. 사내 사진이 없거나 로컬 시험 환경이면 이름 첫 글자가 표시됩니다.

| 항목 | 점수 | 예시 |
|---|---|---|
| 등록한 도구 | 도구마다 5점 | 같은 도구의 v1과 v2는 도구 1개로 계산 |
| 내 도구가 받은 좋아요 | 좋아요마다 2점 | 동료가 좋아요를 취소하면 제외 |
| 내 도구의 다운로드 수 | 같은 사용자와 도구의 조합마다 1점 | 같은 동료가 같은 도구를 반복 수신해도 한 번 |

예를 들어 도구 2개를 등록했고, 동료에게 좋아요 3개와 다운로드 수 7개를 받았다면 10 + 6 + 7 = **23점**입니다. 내가 다른 도구를 내려받거나 좋아요를 누른 활동을 내 공유 점수로 더하지 않습니다.

본인 도구에 대한 본인의 좋아요와 다운로드, 반복 다운로드와 업데이트는 점수를 추가하지 않습니다. 사용 중인 도구의 좋아요를 취소하면 해당 점수는 빠지고, 비활성 사용자는 순위에 표시하지 않습니다. 조회 승인이 필요한 도구의 이름이나 내부 설명을 사용자 순위에 공개하지 않습니다.

도구를 휴지통으로 옮기거나 영구 삭제해도 그동안의 공유 기여도는 유지합니다. 같은 도구를 복원하거나 새 버전을 올린다고 등록 점수가 추가되지 않습니다. 이 기능 적용 전에 이미 영구 삭제되어 집계 자료가 없는 도구는 과거 점수를 복구할 수 없습니다.

## 내 점수와 도구별 내역 확인

**등록 관리 → 내 기여도**에서 내 총점과 등록, 받은 좋아요, 다운로드 수가 각각 몇 점인지 확인합니다. 아래 표에는 내가 등록한 도구별 집계와 점수가 표시됩니다. **사용 중**, **휴지통**, **삭제됨** 상태로 구분하므로 예전에 나눈 도구의 기여도도 함께 확인할 수 있습니다.

도구가 많으면 이전과 다음 페이지로 이동합니다. **새로고침**을 누르면 최근 집계로 다시 확인합니다. 이 화면은 본인의 내역만 보여주며, 다른 사람의 조회 제한 도구를 공개하는 화면이 아닙니다.

## 내 프로필과 연결 KEY

오른쪽 위에는 로그인한 회사 계정의 **이름 TL·부서명·프로필 사진**이 표시됩니다. 사내 사진을 가져올 수 없으면 이름의 첫 글자로 표시하며 다른 기능은 계속 사용할 수 있습니다. 표시되는 이름이나 부서가 실제 정보와 다르면 운영자에게 확인을 요청합니다.

프로필 옆 **열쇠 아이콘 → 내 연결 KEY**에서 내 사번의 인증키를 관리합니다. 이 키는 로컬 프로그램이 나를 확인하는 용도입니다.

1. 내 사번과 사용할 수 있는 기능을 확인합니다. 이름을 입력할 필요 없이 조회·다운로드·좋아요와 신규 등록·내 도구 업데이트가 기본으로 허용됩니다.
2. **연결 KEY 발급 → KEY 복사**를 누릅니다. 원문은 발급 직후 한 번만 표시됩니다.
3. 확장 프로그램은 인증키 입력란을 사용합니다. 로컬 MCP는 AI에 “AI SQUARE 연결해줘”라고 요청한 뒤 같은 채팅에 KEY를 입력합니다. 채팅 KEY는 모델과 대화·도구 호출 기록에 남을 수 있습니다. 공유 파일에는 넣지 않습니다.
4. 분실하거나 교체하려면 **KEY 재발급**을 누릅니다. 이전 키는 즉시 사용할 수 없고 새 키 하나만 활성화됩니다.
5. 이전 키를 사용하던 모든 PC·프로그램의 키도 새 값으로 바꿉니다. 사용하지 않을 때는 **KEY 사용 취소**를 누릅니다.

새로 발급한 KEY에는 유효기간 제한이 없습니다. **KEY 재발급**이나 **KEY 사용 취소**를 누르거나 계정이 비활성화되면 사용할 수 없습니다. 예전에 기간을 정해 발급한 KEY는 기존 만료일이 유지되므로, 기간 제한 없이 사용하려면 재발급합니다. 만료·취소된 옛 KEY가 다시 살아나지는 않습니다.

사번당 활성 키는 하나입니다. 재발급하더라도 등록 자료·권한·이용 이력은 유지됩니다. 개인 KEY로 다른 사람의 도구 수정·삭제·관리자 설정·권한 승인은 할 수 없습니다. 회사 SSO에서 로그아웃해도 KEY가 자동 취소되지는 않습니다.

같은 화면의 **내 PC에서 시작하기**에는 위쪽 **확장 프로그램으로 연결하기**, 아래쪽 **MCP로 연결하기** 안내가 항상 표시됩니다. 확장 프로그램은 **AX Workspace**에서 찾고, MCP는 **로컬 MCP 받기**로 ZIP을 받은 뒤 **MCP 설치 안내서**를 순서대로 따라갑니다. 처음에는 사용하는 AI에 MCP를 한 번 등록하고, 이후 같은 채팅에서 KEY를 연결합니다. MCP 1.5.0부터 KEY 입력과 원본·설치 폴더 확인은 별도 Windows 창 없이 채팅에서 진행하며 `Connect.cmd`는 이 방법만 안내합니다. 확인된 현재 프로젝트는 기본 후보이고, 공통(내 계정) 또는 다른 경로도 선택할 수 있습니다. 예전 MCP는 최신 ZIP을 실제 MCP 실행 폴더에 반영하고 AI를 다시 시작해야 합니다. KEY 발급만으로 모든 앱·서비스에 자동 연결되지는 않습니다. 이 페이지에서는 Skill 연결 안내를 제공하지 않으며 등록용 배포 Skill은 웹 상단 **파일 배포 Skill**에서 계속 받을 수 있습니다.

MCP 1.6.0 이상과 최신 웹 서버에서는 **“이 폴더의 Skill을 공통 업무에 새 도구로 전체 공개 등록해줘”**처럼 요청하면 채팅에서 게시까지 진행합니다. AI가 실제 원본과 준비한 내용을 확인하며, 대상·내용·공개 범위가 명확하면 다시 승인받거나 웹 승인 화면을 열 필요가 없습니다. 필요한 정보가 없거나 요청과 달라진 부분만 채팅에서 확인합니다. 본인 도구의 새 버전도 같은 방식입니다. 별도로 웹에서 먼저 검토하는 방법은 계속 사용할 수 있습니다.

## 상세 내용과 파일 사용하기

카드를 누르고 설치·연결 탭을 확인합니다. 파일 다운로드를 누르면 등록된 원본 파일을 받습니다. URL 연결형은 안내된 주소와 연결 방법을 확인합니다.

- EXE·MSI: 완성된 설치 프로그램입니다. 등록자가 적은 설치 순서와 설치 후 확인 방법을 따릅니다.
- ZIP: 여러 파일을 묶은 패키지입니다. 압축을 푼 뒤 안내한 위치에 놓거나 실행합니다.
- PS1: PowerShell 스크립트입니다. 사내 실행 정책과 등록자의 사용 방법을 확인합니다.
- MD: 단일 Markdown Skill입니다. ZIP으로 변환하지 않고 원본 파일로 받습니다. 안내된 설치 범위를 선택해 해당 위치로 복사합니다.
- 명령어: **사용 시작 → 현재 디렉토리 / 전역·내 계정 → 명령어 복사**를 누른 뒤 터미널에서 직접 실행합니다. 처음에는 어느 범위도 선택되어 있지 않습니다. 지원하지 않는 범위는 회색으로 표시됩니다.
- URL: HTTP 또는 HTTPS로 제공하는 웹 서비스·API·MCP 서버 주소입니다. 사용하는 프로그램에서 등록자의 연결 안내를 따릅니다. 주소를 등록하거나 열기만 해서는 원격 MCP가 자동 설정되지 않습니다.

다운로드만으로 Claude나 ChatGPT에 자동 설치되지는 않습니다. 웹은 ZIP을 EXE로 변환하지 않습니다.

한글과 공백이 들어간 ZIP·설치 파일도 그대로 등록할 수 있습니다. 도구·AX Workspace 파일·기능 요청 첨부는 파일명 대신 고정 ID의 주소로 내려받고, 저장할 때 원본 파일명을 제공합니다. 사용자가 파일명을 영문으로 바꿀 필요는 없습니다. 상단에서 제공하는 기본 배포 Skill과 등록 가이드만 각각 `pt-file-distribution.zip`, `pt-ai-square-user-guide.html`이라는 영문 이름으로 받습니다.

배포 Skill로 정리한 흐름 정보가 있으면 **도구 상세 → 소개**에 **이렇게 동작해요.**가 나타납니다. 예를 들어 “자료 입력 → 내용 정리 → 결과 확인”처럼 단계별로 볼 수 있습니다. 등록자가 설명한 동작 방식이며 현재 실행 상태나 처리 진행률이 아닙니다. 흐름 정보가 없는 도구에는 도식을 억지로 만들지 않고 기존 소개를 표시합니다. 승인형 도구의 흐름은 조회 승인 후 볼 수 있습니다.

## 조회 권한 신청

승인형 도구도 목록에 표시됩니다. 카드를 누르면 조회 권한이 필요하다는 팝업이 나옵니다. 사용 목적을 적고 신청하기를 누릅니다. 승인 결과는 오른쪽 위 종 모양 알림에서 확인합니다. 등록자와 관리자는 바로 조회할 수 있습니다. 플랫폼 조회 승인과 실제 업무 데이터 접근 권한은 별개입니다.

## 여러 사람·팀에 조회 권한 부여하기

**등록 관리 → 해당 기능의 권한**을 누릅니다. 관리자는 **관리자 → 전체 기능 → 권한**에서도 같은 화면을 열 수 있습니다. 권한 관리 탭의 **기능별 권한 설정**에서도 도구를 고를 수 있습니다.

- **사번으로 추가:** 사번을 쉼표·공백·줄바꿈으로 구분해 붙여넣고 **대상 확인**을 누릅니다. 이름과 부서를 확인한 뒤 **선택한 N명 추가**를 누릅니다. 한 번에 최대 100명이며 중복 사번은 한 번만 반영합니다. 로그인 이력이 없는 사번은 확인되지 않은 대상으로 표시되므로 먼저 사이트에 로그인하도록 안내합니다.
- **팀·부서로 추가:** **이름·코드로 검색**, **부서 코드 직접 입력**, **부서명 직접 입력** 중 방식을 선택하고 **대상 확인 → 선택한 대상 추가**를 누릅니다. 검색에는 사이트에 로그인한 구성원의 SSO 부서만 나오며 회사의 모든 부서 목록을 제공하지는 않습니다. 여기서 사용하는 부서는 검색용 조직 분류가 아니라 SSO의 실제 소속입니다.
- **현재 부여한 권한:** 개인과 부서 권한을 구분해서 확인하고 **회수**할 수 있습니다. 둘 중 하나라도 남아 있으면 조회할 수 있습니다. 부서 구성원의 소속은 마지막 SSO 로그인 정보가 기준이며, 부서 이동은 다음 SSO 로그인 때 갱신됩니다.

아직 구성원이 로그인하지 않은 부서는 **부서 코드 직접 입력**을 사용하세요. 예를 들어 `D001, D002`를 입력해 저장하면 이후 해당 코드로 SSO 로그인한 활성 사용자에게 적용됩니다. 이름이 바뀌거나 같은 이름의 부서가 있을 수 있으므로 코드를 아는 경우에는 코드로 등록하는 것을 권장합니다.

**부서명 직접 입력**에 `P&T 기술팀, 공정 분석팀`을 입력하면 SSO 부서명이 각각 정확히 같은 활성 사용자에게 적용됩니다. 이 방식은 해당 사용자에게 부서 코드가 있어도 적용되므로 대상 이름을 확인하세요. 코드인지 이름인지 입력 내용으로 자동 추정하지 않고 선택한 방식대로 저장합니다. 기존 검색에서 코드 없이 추가했던 부서 권한은 계속 코드가 없는 사용자에게만 적용됩니다.

부서 직접 입력은 **쉼표로만** 나눕니다. 각 값의 앞뒤 공백은 제거하고 `P&T 기술팀`처럼 이름 안의 공백은 유지합니다. 빈 항목은 무시하고 중복은 한 번만 추가하며, 한 도구에 부서 규칙을 최대 50개까지 설정할 수 있습니다.

전체 공개 기능에도 미리 설정할 수 있지만 조회 제한은 **승인 후 조회**를 켠 동안만 적용됩니다. 권한은 웹과 MCP의 상세 조회·파일 다운로드에 동일하게 적용됩니다. 연결 KEY로 권한을 추가·회수하는 기능은 제공하지 않습니다.

## 공유 자료 준비

상단 파일 배포 Skill에서 ZIP을 받고 AI 도구에 지침으로 제공합니다. 예: ‘이 프로젝트를 공유할 수 있도록 파일과 사용 설명을 정리해줘. 개인 경로와 비밀번호는 제외해줘.’ Skill은 로컬 배포 파일과 설명을 만들고 검사하는 데서 마칩니다. 서버 주소나 개인 KEY를 요구하지 않으며 검색, 다운로드, 설치, 업로드를 실행하지 않습니다.

완성된 파일은 웹에 직접 올리거나 MCP에 ‘이 ZIP을 AI SQUARE에 등록해줘’라고 요청하세요. MCP는 원본 폴더에서 ZIP을 준비해 게시할 수도 있습니다. 신규 등록인지 본인 도구의 새 버전인지, 분류 조직과 공개 범위를 정한 뒤 진행합니다. 예전 배포 Skill을 설치했다면 기존 폴더의 개인 수정분을 보관하고 최신 ZIP의 폴더로 교체하세요. 단순히 파일을 덮어쓰면 예전 연결 스크립트가 남을 수 있습니다.

| 공유 유형 | 예시 | 준비할 자료 |
|---|---|---|
| MCP/Tool | 문서 검색 MCP, 데이터 처리 프로그램 | 연결 URL 또는 실행·설치 파일 |
| Skill | 주간 보고 지침, Python 처리 코드 | 단일 MD 또는 SKILL.md·scripts·참고 자료를 묶은 ZIP |
| 플러그인/하네스 | Claude 플러그인, 작업 흐름 실행 환경 | 해당 프로그램용 배포 패키지와 연결 안내 |

## 도구 등록 1단계 — 기본 정보

배포 파일을 **배포 파일을 여기에 놓으세요** 영역에 끌어다 놓거나 파일 선택으로 불러올 수 있습니다. 배포 Skill로 만든 ZIP이면 안의 배포 정보를 읽어 이름과 설명, 안내 등을 자동으로 채웁니다. 다른 배포 ZIP으로 교체하면 **신규 파일 내용을 적용하시겠습니까?** 확인창이 나옵니다. 적용하면 새 파일의 정보로 바뀌고, 취소하면 직접 입력한 내용은 유지됩니다. 파일을 바꾼 뒤에는 최종 내용과 실제 첨부 파일을 확인하세요.

이름은 `엑셀 파일 합치기`, `회의록에서 할 일 정리`처럼 무엇을 하는지 짧게 적습니다. 소개에는 어떤 자료를 넣고 어떤 결과를 받는지, 언제 쓰면 좋은지를 1~2문장으로 설명하세요. `업무의 다음 단계를 더 쉽게` 같은 홍보 문구보다 실제 동작을 쓰면 동료가 고르기 쉽습니다. 이름은 50자, 소개는 200자 이내입니다.

제목이나 설명에서 여러 항목을 나열할 때 가운데점을 쓰지 않습니다. `글자와 도형, 표, 차트`처럼 쉼표와 연결 표현으로 쓰고, 길면 문장을 나누세요. 이 기준은 사용 안내와 동작 흐름에도 적용합니다. 코드나 공식 이름은 원래 표기를 유지합니다.

관련 업무 태그에는 동료가 검색할 말을 넣습니다. 엑셀을 합치는 도구라면 실제 기능에 맞게 `엑셀 합치기`, `파일 병합`, `여러 표 모으기` 등을 쓸 수 있습니다. 최대 8개, 각 30자 이내이며 지원하지 않는 업무를 검색용으로 추가하지 않습니다. 설치 조건과 제한은 상세 안내에 남깁니다. 배포 Skill과 MCP로 등록할 때도 같은 기준을 사용하며, 기존에 등록한 설명이 자동으로 바뀌지는 않습니다.

오른쪽 위 도구 등록을 누릅니다. 이름, 소개, 관련 업무 태그를 적고 프로그램·유형·조직·업무를 선택합니다. 관련 업무에는 ‘불량 분석, 수율 검토’처럼 동료가 검색할 말을 적습니다.

소개에는 “점검 기록을 입력하면 이상 항목과 후속 조치를 정리합니다.”처럼 하는 일과 결과를 1~2문장으로 적습니다. 카드에 표시되는 내용이므로 업무 태그만 반복해서 적지 않습니다.

조회 권한 스위치를 끄면 사내 사용자가 바로 상세를 볼 수 있습니다. 켜면 등록자·관리자에게 승인받은 사용자만 상세·파일·피드백을 봅니다. 목록에는 두 경우 모두 표시됩니다. 다음을 누릅니다.

## 도구 등록 2단계 — 파일·연결

파일 등록을 선택하고 파일을 업로드 영역에 끌어다 놓거나 파일 선택을 누릅니다. ZIP·AX 확장(.axextension)·EXE·MSI·PS1·MD 중 하나를 선택합니다. 파일명과 크기가 표시되며, 잘못 골랐다면 파일 옆 X로 취소할 수 있습니다. 선택 시 배포 정보 확인을 위해 임시 전송하며, 게시 버튼을 누르면 정식 보관합니다.

파일 없이 명령어만 배포하려면 **명령어 안내**를 선택합니다. 프로젝트용과 내 계정 전역용 명령어를 각각 적습니다. 지원하지 않는 범위는 비워 두고 설치 안내에 이유를 적습니다. 명령어도 v1·v2로 저장되므로 새 버전 등록과 이전 안내로 복구가 가능합니다. 명령어 복사는 다운로드 횟수로 세지 않습니다.

URL 연결을 선택했다면 `http://` 또는 `https://`로 시작하는 주소를 입력합니다. 사내 주소도 등록할 수 있으며, 필요한 포트와 경로를 포함합니다. 예: `http://mcp.example.internal:8080/mcp`. 아이디·비밀번호를 포함한 주소는 사용할 수 없고, 개인 KEY나 다른 인증정보도 주소에 넣지 않습니다. 인증 방법은 설치·연결 안내에 따로 적습니다.

URL 등록은 연결 주소와 안내를 공유하는 기능입니다. 웹 서버가 등록한 주소에 접속하거나, 원격 MCP를 사용자 프로그램에 자동 설정하지 않습니다. 실제 접속 가능 여부와 인증·연결 방식은 등록자가 확인한 내용을 사용 환경과 설치·연결 방법에 적습니다.

- EXE 예시: ‘Setup.exe 실행 후 Claude를 다시 시작하세요. 도구 목록에 장비 검색이 표시되는지 확인하세요.’
- Skill 예시: ‘ZIP을 풀고 회사에서 사용하는 Skills 위치에 폴더를 추가하세요. 주간 보고 작성을 요청하세요.’
- MCP 예시: ‘프로그램의 MCP 연결 설정에 안내한 URL과 사내 인증 방법을 입력하세요.’

## 도구 등록 3단계 — 확인·게시

설명·권한·파일을 확인하고 게시를 누릅니다. 서버가 크기와 기본 형식을 검사하고 v1처럼 배포 번호를 발급합니다. 원본 형식으로 배포하며 자동 EXE 변환은 하지 않습니다. 기본 파일 검사에 악성코드 검사나 기능 실행 검증은 포함되지 않습니다.

## 수정·새 버전·롤백

등록 관리에는 내가 등록한 기능만 나옵니다. 수정에서 설명과 분류를 바꿉니다. 파일을 바꾸려면 버전 → 새 버전 등록을 누릅니다. v2, v3 번호는 자동 발급됩니다. 등록자·관리자만 수정·삭제·버전 변경을 할 수 있습니다.

**새로 만든 파일도 기존 도구의 새 버전으로 올릴 수 있습니다.** 기존 카드의 **버전 → 새 버전 등록**에서 새 파일을 선택하세요. 파일 이름·내부 코드·ZIP의 `packageId`가 달라도 선택한 도구에 v2·v3으로 등록됩니다. 식별자를 맞추려고 ZIP을 수정하거나 다시 압축할 필요가 없습니다.

- **도구 ID**는 플랫폼이 신규 등록할 때 자동 발급하는 숫자입니다. 기존 도구를 업데이트해도 바뀌지 않으며 파일에 새로 적을 필요가 없습니다.
- **플랫폼 packageId**는 처음 정상적으로 읽힌 배포 파일의 식별자입니다. 플랫폼은 이 값을 고정하여 유지합니다. 새 버전 화면에서 확인·복사할 수 있으며, 새 ZIP에 같은 값을 직접 적을 필요는 없습니다.
- **파일의 원본 packageId**는 새 ZIP의 `ai-square.json`에 적혀 있는 값입니다. 플랫폼 값과 다르면 두 값을 안내하고 그대로 새 버전으로 등록합니다. ZIP의 원본 바이트는 바꾸지 않습니다.
- AI에는 **“내가 등록한 도구 ID 123을 이 새 ZIP으로 업데이트해줘.”**처럼 대상을 지정합니다. 번호는 실제 도구 ID로 바꾸세요. 대상을 모르면 기존 도구 후보를 확인해 선택합니다. 다른 기능이면 별도 도구로 신규 등록합니다.

배포 정보가 없던 도구는 처음 정상적인 선언이 들어온 버전의 packageId를 고정합니다. 일반 파일은 계속 내용을 직접 입력해 등록할 수 있습니다. 파일 형식·용량·ZIP 경로·필수 파일 검사와 수정 권한은 유지됩니다. 설치 경로나 실행 방법을 바꾼 파일이라면 실제 파일에 맞는 설치 정보와 안내를 확인해야 합니다.

배포 문제가 있으면 버전에서 이전 버전의 이 버전으로 복구를 누릅니다. 서버의 배포 버전이 바뀌며 사용자 PC 파일을 자동으로 덮어쓰지는 않습니다. 현재 배포와 복구용 보호 버전은 삭제할 수 없습니다. 권한 관리에서는 신청 승인·반려·권한 회수·직접 사용자 추가를 할 수 있습니다.

동작 흐름도 배포 버전에 연결됩니다. 흐름을 바꿀 때는 배포 자료를 수정해 새 버전으로 등록합니다. 이전 버전으로 복구하면 그 버전의 흐름을 표시하고, 해당 버전에 흐름 정보가 없으면 도식을 표시하지 않습니다.

## 피드백과 개인 알림

도구 상세의 의견 탭에서 오류나 개선 의견을 남깁니다. 다른 사람이 내 도구에 의견을 남기면 등록자와 관리자에게 알림이 도착하고, 답변은 의견 작성자에게도 알려줍니다. 본인이 작성한 의견·답변은 본인에게 알리지 않습니다. 알림을 누르면 해당 도구의 의견 탭으로 이동합니다.

등록자·관리자가 답변과 처리 상태를 남길 수 있습니다. 업데이트 알림 받기는 새 버전 소식을 위한 설정이며, 이 설정을 꺼도 내 도구에 달린 의견은 알립니다. 종 모양에 의견·답변·권한 결과·버전 소식이 모입니다. 화면이 열려 있을 때 약 30초마다, 다른 탭에서 돌아왔을 때에도 알림을 확인합니다.

## 새 기능 요청과 첨부 자료

기능 요청 → 새 기능 요청을 누릅니다. 불편한 점과 원하는 결과를 적고 관련 업무를 선택합니다. 이미지나 예시 파일을 끌어다 놓거나 파일 선택을 누릅니다. 최대 5개, 파일당 20MB이며 PNG·JPG·WEBP·PDF·TXT·CSV·XLSX·DOCX·ZIP을 지원합니다. 파일 옆 X로 게시 전 선택을 취소합니다.

등록 후 상세 화면의 첨부 자료에서 다운로드할 수 있습니다. 요청과 자료는 사이트 사용자가 함께 볼 수 있으므로 공유 가능한 자료만 첨부하세요.

개발자는 제가 구현할게요를 눌러 담당자가 되고 답변과 개발 중 상태를 남깁니다. 완성 후 구현 완료를 선택하고 등록된 기능을 연결합니다. 요청자는 개인 알림으로 진행 상황을 확인합니다.

## 배포 Skill로 준비한 ZIP 등록하기

상단의 파일 배포 Skill은 플랫폼에 포함된 기본 자료입니다. 개인 KEY나 다운로드 주소 설정 없이 받을 수 있습니다. 파일을 받을 수 없다는 안내가 나오면 운영자에게 최신 배포 자료가 서버에 반영됐는지 확인을 요청하세요.

1. 상단 **파일 배포 Skill → Skill ZIP 다운로드**를 누르고 압축을 풉니다.
2. AI 도구에 Skill을 제공하고 “이 프로젝트를 ai-square.json과 설치 안내가 포함된 P&T AI SQUARE 배포 ZIP으로 준비해줘. 카드 소개와 실제 동작 흐름도 정리해줘”라고 요청합니다. 만들어진 코드·소개·단계·설치 안내가 실제 기능과 맞는지 확인합니다.
3. 웹의 **도구 등록 → 배포 파일에서 불러오기**를 누르고 결과 ZIP을 선택합니다. 파일은 검사하기 위해 임시 전송되고 검사 후 서버 임시 파일은 삭제됩니다. 아직 게시되지는 않습니다.
4. **배포 정보 확인 완료**를 확인합니다. 처음 파일을 선택한 빈 양식에는 이름과 소개, 프로그램, 유형, 관련 업무 태그와 설치 안내가 자동 입력됩니다. 다른 배포 파일로 바꾸면 새 내용을 적용할지 확인창에서 선택합니다. 적용을 취소했거나 이미 내용을 작성한 첫 파일, 새 버전 등록은 **배포 정보를 입력란에 적용**으로 원하는 때 가져올 수도 있습니다.
5. 조직·업무 분야·담당자·조회 권한은 직접 선택합니다. 이름·소개·안내는 검토 후 수정할 수 있으며 프로그램·유형은 ZIP 선언과 일치해야 합니다.
6. **다음 → 파일·연결 → 확인·게시**를 진행합니다. 서버가 실제 올라온 파일을 다시 검사하고 배포 번호를 발급합니다.
7. 게시 완료 화면에서 **배포 정보 JSON 받기**를 누르면 도구 ID·배포 번호·버전 확인 주소가 연결된 파일을 받습니다. 나중에도 **상세 → 사용 시작 / 버전**에서 받을 수 있습니다.

예를 들어 ZIP의 배포 정보에 적힌 시작 파일이 없으면 **배포 정보를 읽지 못했습니다**와 원인을 표시합니다. 파일을 다시 준비하거나, 이름·유형·설치 안내를 직접 작성해서 그대로 게시할 수 있습니다. 읽기 실패 때문에 업로드를 막지 않습니다. 손상된 ZIP·안전하지 않은 내부 경로·허용하지 않는 파일 형식은 별도의 기본 검사에서 차단됩니다. 파일 검사는 코드의 정상 작동이나 보안을 보증하지 않습니다.

Skill은 확인한 동작을 최대 8단계로 정리합니다. 웹 서버가 설명 문장을 임의로 해석하거나 코드를 실행해서 흐름을 만드는 방식은 아닙니다. 단일 MD를 자동 등록하는 경우에도 별도 등록 정보에 흐름을 넣을 수 있으므로 흐름 때문에 ZIP으로 바꿀 필요가 없습니다.

파일은 원본 그대로 배포합니다. ZIP을 EXE로 바꾸거나 설치 명령을 서버에서 실행하지 않습니다. 별도의 배포 정보 JSON은 설치 프로그램이 아니며, 실제 설치 후 어떤 배포를 사용 중인지 기록하고 버전 확인을 연결할 때 참고하는 정보입니다. 버전 확인 코드는 제작자가 실행 지점에 연결해야 합니다.

기존 ZIP·EXE·MSI·PS1도 등록할 수 있습니다. ai-square.json이 없으면 **일반 파일 등록**으로 표시되고 직접 입력합니다. 새 버전의 packageId가 달라도 기존 도구를 선택하면 그 도구의 최초 식별자를 유지해 등록합니다. 원격 MCP URL은 기존 URL 등록 방식으로 안내합니다. 샘플 데이터 모드는 조회 전용이므로 실제 등록과 검사는 실제 데이터 모드에서 진행합니다.
## 저장 공간이 부족하다고 표시될 때

관리자는 **관리자 → 저장 공간**에서 현재 사용량과 남은 공간을 확인합니다. **직접 지정**으로 플랫폼 최대 용량을 정하거나 **서버 여유 공간에 맞추기**로 자동 계산을 선택합니다. 서버에 남겨둘 공간을 입력한 뒤 **한도 저장**을 누릅니다.

예를 들어 디스크에 100GB가 남아 있고 10GB를 남겨두도록 설정하면 자동 모드에서 약 90GB를 더 저장할 수 있습니다. 한도를 낮춰도 이미 올린 파일은 삭제되지 않습니다. 파일을 정리하려면 **이전 버전 정리 → 정리 대상 확인**에서 대상을 확인합니다. 일반 사용자는 용량 설정을 변경할 수 없으므로 관리자에게 조정을 요청합니다.


## 사용 이력을 기간별로 확인하고 다운로드하기

관리자는 **관리자 → 사용 이력**에서 도구 다운로드·좋아요·좋아요 취소를 표로 확인합니다. 기본 조회 기간은 **최근 30일**이며, 날짜와 시각은 **한국 시간(KST)** 기준입니다.

1. 최근 7일·30일·90일을 선택하거나 시작일과 종료일을 직접 지정합니다. 종료일의 이력까지 포함합니다.
2. 필요한 경우 활동 유형을 선택하고 **조회**를 누릅니다. 조건을 바꾸면 첫 페이지부터 확인합니다.
3. 한 페이지에 25·50·100개씩 표시할 수 있습니다. **이전 / 다음**으로 이동하므로 이력이 많아도 화면에 카드가 계속 쌓이지 않습니다.
4. **CSV 다운로드**를 누르면 화면에 적용된 기간과 활동 유형에 해당하는 전체 이력을 받습니다. 현재 페이지의 행만 내보내는 기능이 아닙니다. 날짜를 입력만 하고 조회하지 않았다면 이전 조회 조건으로 내려받습니다.

CSV는 Excel에서 한글을 읽을 수 있는 UTF-8 BOM 형식입니다. 한 번에 최대 **50,000건**까지 다운로드하며, 이를 넘으면 기간을 나누어 조회합니다. 초과 이력을 조용히 잘라서 저장하지 않습니다.

이 표의 범위는 도구의 다운로드·좋아요 활동입니다. 조회수, 게시·관리 작업, AX Workspace 설치 파일의 다운로드 이력은 포함하지 않습니다. 반복 다운로드와 업데이트도 기록되지만 순위 집계는 사용자·도구별 최초 다운로드를 기준으로 합니다. 과거 기록에서 이용 경로를 확인할 수 없으면 `—`로 표시하며, 도구명과 사용자 이름은 현재 등록 정보를 기준으로 표시합니다.

## AX Workspace 다운로드

상단 **AX Workspace**에서 **전체 / AX Workspace / 확장 프로그램 / 연동 도구**로 자료를 찾아 내려받습니다. 카드의 설명과 배포 버전을 확인한 뒤 **다운로드**를 누르세요. 설치 파일은 원본 형식으로 내려받으며 다운로드 자체가 PC 설치를 실행하지는 않습니다. 이전에 ‘기타’로 등록된 자료는 ‘연동 도구’에서 볼 수 있습니다.

관리자는 **AX Workspace → 파일 등록**을 누르고 이름, 설명, 분류를 입력한 다음 파일을 선택하거나 끌어놓습니다. 배포 버전은 **v1 · 자동**으로 표시됩니다. **파일 등록**을 누르면 모든 로그인 사용자에게 표시됩니다. 일반 사용자에게는 등록 버튼이 나타나지 않습니다. CUBE 연동이나 AI SQUARE 연결 확장 프로그램이 준비되면 같은 화면에 추가로 등록할 수 있습니다.

**다운로드한 AX 프로그램의 새 버전도 알림을 받을 수 있습니다.** 카드의 파일을 다운로드하면 내 사번으로 업데이트 알림이 자동으로 켜집니다. 다운로드하지 않고도 카드의 알림 버튼으로 켜거나 끌 수 있습니다. 알림을 끈 뒤 파일을 다시 받아도 꺼진 상태는 유지됩니다. AX 다운로드는 일반 도구의 다운로드 수나 구성원 순위에 합산하지 않습니다.

관리자가 같은 프로그램을 업데이트할 때는 **기존 카드의 새 버전 등록 → 새 파일 선택 → 새 버전 등록** 순서로 진행합니다. 다음 배포 번호가 **v2 · 자동**, **v3 · 자동**으로 표시되며 게시가 성공하면 서버가 번호를 부여합니다. 파일 이름은 달라도 되고 버전을 직접 입력할 필요가 없습니다. 이 번호는 플랫폼 배포 순서이며 프로그램 자체의 1.2.0 같은 버전은 설명에 적을 수 있습니다.

상단 **파일 등록**은 별개 프로그램의 새 카드를 만드는 기능이므로, 기존 사용자에게 업데이트를 알리려면 기존 카드에서 새 버전을 등록해야 합니다. 파일 이름만 보고 다른 카드와 자동 합치지는 않습니다. 이전 파일은 서버에 보존되며 새 파일을 자동으로 PC에 설치하거나 교체하지 않습니다.

새 버전 알림은 웹 오른쪽 위 **종 아이콘**에서 확인하며 알림을 누르면 해당 AX 카드로 이동합니다. 웹 화면이 보이는 동안 약 30초마다 새 알림을 확인합니다. Windows 알림이나 CUBE 메시지를 보내는 기능은 아닙니다. 이 기능 적용 전에 AX 파일을 받은 이력은 남아 있지 않으므로, 예전에 받았던 프로그램은 **다시 다운로드하거나 카드에서 알림을 켜주세요.**

예를 들어 **P&T AI Square 연결 확장**은 배포자가 서버 주소가 포함된 `.axextension` 파일을 준비하고 관리자가 AX Workspace에 등록합니다. 사용자는 확장 파일 열기를 지원하는 최신 AX Workspace 앱을 설치한 뒤, 내려받은 `.axextension` 파일을 **두 번 클릭**합니다. 앱에서 표시하는 이름·서버 주소·설치 위치를 확인해 설치한 다음, 연결 화면에 본인의 개인 KEY를 입력합니다. HTTP 서버라면 비암호화 연결 안내도 확인합니다. 기존 ZIP도 앱의 **설정 → 추가 기능**에서 가져올 수 있습니다. 파일 연결을 지원하지 않는 이전 앱은 먼저 업데이트해야 합니다.

AX 확장 파일은 ZIP과 같은 압축 구조를 사용하지만 압축을 풀지 않고 AX Workspace에서 엽니다. Claude Skill이나 MCP에 설치하는 파일이 아니며 별도의 설치 EXE가 필요하지 않습니다. 웹은 관리자가 업로드한 원본을 그대로 전달하며 EXE를 추가하거나 서버 주소를 자동 입력하지 않습니다. 개인 KEY는 배포 파일에 넣지 않습니다. EXE를 제외한 구성이라는 사실만으로 V3 차단이 해소되거나 검증되었다는 뜻은 아니므로 실제 사내 PC의 확인이 필요합니다.

오른쪽 위 **열쇠 아이콘**에서는 개인 KEY를 발급·재발급합니다. **내 PC에서 시작하기**의 위쪽 **확장 프로그램으로 연결하기**에서 AX Workspace 탭으로 이동해 연결 프로그램을 찾습니다. 아래쪽 **MCP로 연결하기**에는 ZIP 다운로드와 설치 안내서가 항상 표시됩니다. 이전 고정 확장 다운로드 주소로 접속해도 AX Workspace 탭으로 이동합니다.

## 기능 요청 관리와 휴지통

기능 요청은 목록의 카드를 클릭하면 내용을 확인할 수 있습니다. 관리자는 개발을 직접 맡지 않아도 **진행 상태**를 바꿀 수 있습니다. **구현 완료**로 바꿀 때는 실제 등록된 기능을 선택합니다. **답변·상태 저장**을 누르면 반영됩니다.

관리자에게 표시되는 **요청 삭제**는 요청 내용·답변·첨부파일을 삭제합니다. 확인 창에서 대상 이름을 확인하고 진행하세요. 이 작업은 복원할 수 없습니다.

도구를 일반 삭제하면 **등록 관리 → 휴지통**으로 이동하며 등록자 또는 관리자가 복원할 수 있습니다. 전체 휴지통은 **관리자 → 휴지통**에서 확인합니다. 관리자는 그곳의 **영구 삭제**로 모든 배포 버전과 파일, 관련 권한과 피드백, 개별 활동 기록을 삭제할 수 있습니다. 등록자의 기여도를 유지하기 위한 도구 이름과 합계는 남습니다. 연결되어 있던 기능 요청 자체는 남고 삭제된 도구 연결은 해제됩니다. 영구 삭제한 파일과 본문은 복원할 수 없습니다.

삭제가 도중에 멈추면 **관리자 → 휴지통 → 삭제 다시 시도**를 누릅니다. 이미 삭제된 부분을 다시 만들지 않고 남은 파일·데이터 정리를 이어갑니다.


## AI 몰입룸 예약

상단 **AI 몰입룸**에서 달력과 예약 현황을 확인합니다. AI 과제 개발에 집중하고 동료들과 개발 경험과 고민을 나누는 공간입니다.

1. 달력에서 하루를 클릭하거나 시작일부터 종료일까지 드래그합니다. 신청 창의 날짜를 직접 바꿔도 됩니다.
2. 사용 시간은 기본 **종일**입니다. 필요한 경우 **오전** 또는 **오후**를 선택합니다. 여러 날을 선택하면 각 날짜에 같은 시간대가 적용됩니다.
3. 예약 제목과 사용 목적을 적고 신청합니다. 일반 구성원의 신청은 **승인 대기**, 관리자의 신청은 바로 **승인됨**으로 표시됩니다.
4. 달력의 예약을 클릭하면 신청자 이름과 조직, 사용 목적, 기간, 처리 상태를 확인할 수 있습니다. 관리자는 이 화면 또는 **관리자 → 몰입룸 신청**에서 신청을 승인하거나 반려하고 예약을 취소할 수 있습니다. 본인은 본인 예약을 취소할 수 있습니다.
5. 일반 구성원이 신청하면 관리자에게 종 모양 알림이 전달됩니다. 관리자는 알림을 눌러 예약 내용을 열거나 **관리자 → 몰입룸 신청**에서 처리할 수 있습니다. 관리자가 승인, 반려 또는 취소하면 신청자에게도 결과가 알림으로 전달됩니다. 알림을 클릭하면 해당 예약의 내용과 처리 사유가 표시됩니다.

승인 대기 중에도 해당 시간은 확보됩니다. 같은 날 오전과 오후를 서로 다른 사람이 신청할 수 있지만, 종일 예약과 겹치는 신청은 할 수 없습니다. 반려 또는 취소하면 해당 시간이 다시 열립니다. 날짜나 시간대를 바꾸려면 기존 예약을 취소하고 다시 신청합니다.

날짜는 한국 시간 기준이며 지난 날짜의 새 신청은 받지 않습니다. 한 번에 최대 31일까지 신청할 수 있습니다. 주말과 공휴일도 표시하지만, 표시만으로 예약을 막지는 않습니다. 연속 기간에는 주말과 공휴일도 포함되므로 신청 전에 날짜를 확인해 주세요.

공휴일은 우주항공청과 한국천문연구원의 **2026~2027년 자료**를 포함합니다. 사내 휴무일은 별도 회사 운영 일정과 확인해 주세요. 자료 범위 밖의 날짜는 공휴일 정보가 없다는 안내가 표시됩니다.
