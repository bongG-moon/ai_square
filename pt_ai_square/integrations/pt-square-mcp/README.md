# P&T AI SQUARE 로컬 MCP

Claude Code 등 **로컬 stdio MCP를 지원하는 프로그램**에서 실행합니다. 별도 MCP 호스팅 서버나 포트를 열지 않습니다. 기존 AI SQUARE 웹 서버에는 연결되어야 합니다. MongoDB 주소·계정·웹 서버 폴더 접근 권한은 이 패키지에 포함되지 않습니다.

## 1. 사이트에서 받고 KEY만 입력하세요

Python **3.11 이상**이 설치된 Windows PC에서 사용합니다.

1. AI SQUARE 웹에 로그인하고 우측 상단 **열쇠 아이콘**을 누릅니다.
2. 도구 등록도 사용하려면 **업로드 포함 → 연결 KEY 발급**을 선택합니다. 조회·다운로드만 사용하면 읽기 KEY로도 연결할 수 있습니다. 이미 보관 중인 유효한 KEY는 그대로 사용할 수 있습니다.
3. 같은 화면의 **다른 방식으로 연결하기 → AI에서 MCP로 연결하기**를 펼치고 **로컬 MCP 받기**로 ZIP을 받은 뒤 압축을 풉니다.
4. 압축을 푼 폴더의 **`Connect.cmd`를 더블클릭**합니다.
5. 자동으로 표시된 사이트 주소를 확인하고 **개인 KEY** 입력란에 붙여넣습니다. HTTP 주소라면 암호화되지 않은 연결 안내에 체크합니다.
6. **연결하기**를 누릅니다. 서버에서 본인 계정을 확인한 뒤 이름·부서가 표시되면 연결 완료입니다.

사이트에서 받은 ZIP의 `connection.json`에는 **다운로드한 사이트 주소만** 들어 있습니다. KEY나 사번은 들어 있지 않습니다. 서버 주소와 작업 폴더를 직접 입력하지 않아도 됩니다. GitHub 저장소에서 직접 받은 공통 ZIP에는 사이트 주소가 없으므로, 처음 연결할 때는 웹에서 다시 받거나 아래 고급 설정의 `--url`을 사용하세요.

이 로컬 MCP는 Python 코드가 담긴 ZIP으로 제공하며 EXE 설치 파일로 자동 변환하지 않습니다. 완성된 앱·플러그인 설치 파일은 **AX Workspace** 탭에서 관리자가 별도로 등록해 배포합니다.

기본 다운로드 폴더는 자동 생성됩니다.

```text
C:\Users\내계정\AI_SQUARE\downloads\
```

다운로드 파일은 `downloads/server-서버식별자/tool-도구ID/v버전/` 아래에 구분하고, 받은 결과에 실제 경로를 표시합니다. 로컬 시험 사이트와 운영 사이트에 같은 도구 ID가 있어도 파일이 섞이지 않습니다. **다운로드 위치와 설치 위치는 다릅니다.** 실제 설치는 요청할 때 프로젝트 또는 내 계정 범위를 선택합니다. 기본 폴더가 생겼다고 PC 전체에 접근 권한이 생기는 것은 아닙니다.

KEY는 실제 인증 성공 후 현재 Windows 사용자에게 묶인 DPAPI로 암호화해 보관합니다. KEY 원문을 채팅·실행 명령줄·MCP 설정 JSON에 넣지 않습니다. 잘못된 KEY 또는 접속 실패로 기존에 정상 연결된 설정을 덮어쓰지 않습니다. KEY가 바뀌면 아래 **KEY 다시 연결** 절차를 사용하세요. 연결 성공 후 다음 작업부터 새 KEY를 읽으므로 MCP를 재설치할 필요는 없습니다. MCP 코드 자체를 교체했다면 AI 프로그램을 다시 시작합니다.

## 2. 처음 사용하는 경우에만 AI 프로그램에 MCP 등록

이미 Claude Code 등에 `pt-ai-square`가 등록되어 있다면 **같은 경로에 새 파일을 반영한 뒤 KEY 연결과 AI 프로그램 재시작만** 진행합니다. 같은 MCP를 반복해서 추가할 필요는 없습니다. 압축을 푼 위치를 바꾸었다면 AI 프로그램에 등록된 실행 경로도 새 위치로 맞춰야 합니다.

처음 사용하는 경우에는 압축을 푼 폴더에서 PowerShell을 열고 실행합니다.

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

공식 MCP Python SDK **1.30.0**을 이 MCP 전용 가상환경에 설치합니다. 회사망에서 pip가 차단되어 있다면 회사의 Python 패키지 저장소를 사용하세요. 관리자 권한이나 전역 Python 변경은 필요하지 않습니다. KEY 연결 창은 Python 기본 기능으로 동작하므로 SDK 설치보다 먼저 실행해도 됩니다.

해당 프로그램의 MCP 설정에 아래 항목을 추가합니다. 실제 압축 해제한 **절대 경로**로 바꾸세요. 기존 MCP 항목을 지우지 말고 `mcpServers` 안에 한 항목만 추가합니다.

```json
{
  "mcpServers": {
    "pt-ai-square": {
      "command": "C:\\도구\\pt-square-mcp\\.venv\\Scripts\\python.exe",
      "args": ["C:\\도구\\pt-square-mcp\\run_mcp.py", "serve"]
    }
  }
}
```

여기에 KEY를 넣지 않습니다. 등록 범위는 사용하는 프로그램에서 **현재 프로젝트 / 내 계정** 중 선택하세요. AI 프로그램을 다시 시작한 뒤 “AI SQUARE 연결 상태 확인해줘”라고 요청하면 사번·부서·연결 권한을 확인할 수 있습니다. 웹 전용 ChatGPT처럼 로컬 stdio를 직접 지원하지 않는 환경에는 이 JSON을 그대로 붙여 넣어 연결할 수 없습니다.

Claude의 `Connected`는 로컬 MCP 프로세스와 통신한다는 뜻입니다. **AI SQUARE 계정 연결 완료는 실제 서버 인증에 성공했을 때** 확인됩니다.

## KEY가 만료·취소·재발급되었을 때 다시 연결하기

MCP 요청에서 **401 인증 오류**가 나면 현재 연결된 서버의 **KEY 발급 화면 링크**와 다시 연결하는 방법을 보여줍니다. 링크는 현재 MCP 설정의 서버 주소에 `/local-access`를 붙인 주소입니다. 예를 들어 `http://회사서버:5000`에 연결 중이면 `http://회사서버:5000/local-access`로 안내하며 다른 사이트로 보내지 않습니다.

1. 오류 안내에 표시된 **KEY 발급 화면 링크**를 누르고 회사 웹에 로그인합니다.
2. **내 연결 KEY → KEY 재발급**에서 필요한 허용 작업을 선택하고 새 KEY를 복사합니다. 재발급하면 같은 사번의 이전 KEY는 사용할 수 없습니다. 계정이 비활성화된 경우에는 재발급으로 해결되지 않으므로 운영자에게 확인합니다.
3. AI에게 **“AI SQUARE KEY 다시 연결해줘”**라고 요청합니다. AI는 인자가 없는 `reconnect_key` 도구로 개인 KEY 입력 창을 엽니다. **KEY 값은 채팅이나 도구 인자로 전달하지 않습니다.**
4. 창에 표시된 서버가 맞는지 확인하고 **가려진 개인 KEY 입력란**에 새 KEY를 붙여넣습니다. HTTP 안내를 확인한 뒤 **연결하기**를 누릅니다.
5. 본인 이름·부서가 표시되면 완료입니다. 다음 검색·다운로드 요청부터 새 KEY로 인증합니다. MCP나 이미 설치한 도구를 다시 설치할 필요는 없습니다.

`reconnect_key`는 실행 중인 MCP가 사용하는 설정의 **현재 서버 주소(`Settings.url`)**로 다시 연결합니다. 고급 설정으로 다른 서버나 별도 `--config`를 사용하더라도 그 연결을 기준으로 합니다. 아직 연결된 설정이 없다면 먼저 웹에서 받은 ZIP의 `Connect.cmd`로 최초 연결하세요.

`Connect.cmd`를 직접 여는 방법도 계속 사용할 수 있습니다. 이 방법은 ZIP에 담긴 사이트 주소를 사용할 수 있으므로 **현재 MCP에 연결된 서버와 같은 주소인지 확인**하세요. 별도 설정이나 다른 서버를 사용하는 경우에는 현재 MCP에서 `reconnect_key`를 요청하는 편이 정확합니다. 예전 MCP에 이 도구가 없다면 최신 ZIP을 기존 위치에 반영하고 AI 프로그램을 한 번 다시 시작합니다.

재연결은 인증정보만 갱신합니다. 중단된 설치·업로드를 자동으로 다시 실행하지 않습니다. 등록이나 설치 결과가 불명확했다면 결과를 먼저 확인하세요. **게시 초안은 생성 당시 KEY ID에 묶여 있으므로 KEY 재발급 후에는 새 초안을 만들고 웹에서 다시 승인**해야 합니다. 이미 게시된 도구·버전과 PC에 설치한 파일은 유지됩니다.

## 연결 창을 사용할 수 없을 때 / 고급 설정

Python에 Tk가 없어 연결 창이 열리지 않으면 같은 폴더의 PowerShell에서 실행합니다. 웹에서 받은 ZIP이면 주소와 폴더 옵션을 넣지 않습니다.

```powershell
python .\run_mcp.py setup
```

HTTP이면 짧은 확인 질문에 답하고, KEY를 숨김 입력란에 넣습니다. 주소를 다시 타이핑할 필요는 없습니다. 실제 연결은 다음 명령으로도 확인할 수 있습니다.

```powershell
python .\run_mcp.py status
```

공통 ZIP을 직접 받았거나 다른 사이트에 연결할 때만 `--url "http://회사서버주소"`을 사용합니다. 업로드 원본 또는 프로젝트 폴더가 기본 범위 밖이면 AI가 여는 **폴더 선택 창**에서 그 폴더를 직접 선택할 수 있습니다. 선택을 취소하면 접근 범위가 늘어나지 않습니다. 고급 설정의 `--workspace "C:\내작업폴더"`로 기존 폴더를 추가할 수도 있습니다. 드라이브 전체는 허용하지 않습니다. 일반 검색·다운로드에는 이 옵션이 필요 없습니다.

설정 위치는 `%USERPROFILE%\.pt-ai-square\mcp\config.json`입니다. 별도 설정을 쓰려면 명령의 맨 앞에 `--config "C:\별도폴더\config.json"`을 넣습니다. `.env`를 사용하지 않습니다.

자동화 또는 Windows 이외 환경의 `--token-from-env`는 **KEY를 저장하지 않고**, 실행할 때마다 `PTAI_API_TOKEN` 환경변수에서 읽습니다. MCP를 실행하는 프로세스에도 같은 환경변수가 필요합니다. 이 방식을 계속 사용할 때 KEY를 재발급했다면 실행 환경의 `PTAI_API_TOKEN`을 새 값으로 갱신하고 **AI 프로그램을 다시 시작**해 변경된 환경변수를 받게 합니다. 비대화형 HTTP 연결은 사용자가 확인한 정확한 주소를 `--accept-http-origin "http://회사서버주소"`으로 지정합니다. HTTP 확인은 전송 암호화를 제공하지 않으며 일반 웹 포트나 실행 방식을 바꾸지 않습니다.

## 실제 사용 예

- “메일 조회 도구 추천해줘. 같은 부서에서 많이 쓰는 것도 알려줘.”
- “최근 7일 순위 TOP 10 보여줘.” / “누적 순위로 보여줘.”
- “첫 번째 Skill을 현재 프로젝트에 설치해줘.” → 설치 위치·변경 내용 확인 → 파일 받기·해시 검사·배치.
- “설치한 도구에 새 버전이 있는지만 확인해줘.” → 교체하지 않고 확인 결과만 반환.
- “이 폴더를 Skill로 등록해줘.” → 원문 확인·소개와 동작 흐름 작성 → 기존 본인 도구 후보 확인 → 신규/업데이트·조직·업무·공개 범위 선택 → ZIP/MD 준비 → 웹 승인 → 게시.

등록 정보는 사용하는 AI가 실제 소스와 지침을 읽고 작성합니다. MCP나 웹 서버에 별도 LLM 키는 필요하지 않습니다. 여러 파일 폴더는 `ai-square.json` v1에 맞는 ZIP으로 준비하고, 단일 MD는 **그대로 MD**로 등록합니다. 단일 ZIP을 입력하면 원본을 유지합니다. `installProfile`은 등록 메타데이터의 별도 속성이며 ZIP v1 선언 안에 넣지 않습니다.

## 설치 지원 범위

| 유형 | 지원 범위와 결과 |
|---|---|
| Claude Skill MD | 선택한 프로젝트 또는 내 계정의 `.claude/skills/<slug>/SKILL.md`에 복사하고 내용 확인 |
| Claude Skill ZIP | ZIP 최상위 SKILL.md와 보조 파일을 같은 위치에 함께 배치 |
| Python/Node MCP ZIP | 시작 파일·런타임 확인, 프로젝트 `.mcp.json` 또는 내 계정 `.claude.json`에 지정 MCP 항목 추가. 다른 항목 보존. 연결 설정 완료와 실제 MCP 핸드셰이크 성공은 구분 |
| EXE·MSI·PS1 | 사용자가 확인한 범위별 선언 인자로 설치기를 실행. 관리자 승격·실행 정책 우회 없음. `launched`는 설치 완료가 아님. `verify_install`은 선언한 결과 파일 존재만 확인 |
| URL·터미널 명령·지원하지 않는 호스트 | 상세의 연결·설치 안내 제공. 일반 임의 명령 실행 도구는 제공하지 않음 |

자동 설치는 등록자가 올바른 `installProfile`을 명시한 항목만 지원합니다. 의존성 pip/npm 설치는 자동 실행하지 않습니다. 기존 도구에 선언이 없으면 수동 설치 안내로 연결됩니다.

프로젝트/내 계정 범위는 **기본값이 없습니다**. 준비안에 보이는 경로와 인자를 확인한 뒤 설치합니다. 새 버전·설정·로컬 파일이 바뀌면 준비안을 다시 생성해야 합니다. 이 MCP가 설치한 파일과 해당 MCP 설정은 백업·복구할 수 있지만, 사용자가 바꾼 파일을 덮어쓰거나 EXE가 바꾼 시스템 상태를 되돌리지는 않습니다.

파일·설정 변경 전에 복구 기록을 저장합니다. 설치나 복구 중 프로세스가 강제로 종료된 경우, 다음 설치 준비·검증·복구에서 승인된 파일 해시와 현재 상태를 비교합니다. 이미 완료된 결과는 기록만 확정하고 미완료 변경은 원상 복구하며, 사용자가 추가로 변경한 파일·설정은 보존하고 확인 필요 상태로 안내합니다. 이 과정에서 파일을 다시 다운로드하거나 EXE를 자동 재실행하지 않습니다.

## 등록용 설치 선언 예

단일 MD 또는 최상위 SKILL.md가 있는 ZIP의 등록 metadata에 넣습니다.

```json
{
  "installProfile": {
    "schemaVersion": 1,
    "kind": "skill",
    "host": "claude",
    "slug": "memo-summary",
    "scopes": ["project", "user"],
    "entrypoint": "SKILL.md"
  }
}
```

MCP는 `kind: "mcp"`, 실제 `entrypoint: "server.py"`와 `command: {"executable":"python", "args":["{entrypoint}"]}`를 사용합니다. 실행 인자는 `{entrypoint}`, `{installDir}`, `{scopeDir}`만 치환하며 셸로 해석하지 않습니다. EXE·MSI·PS1은 `kind: "installer"`와 `installerArgs: {"project":["실제 지원 인자"], "user":["실제 지원 인자"]}`를 명시합니다. 실제 설치기에서 지원하지 않는 옵션을 만들지 마세요. 범위를 지원하지 않으면 `scopes`에서 빼고 이유를 guide에 적습니다.

## 권한과 데이터

- 검색·다운로드·본인 도구 신규/버전 게시만 제공합니다. 다른 사람 도구 수정, 관리자 설정, DB 명령, 임의 서버 파일 경로 API는 제공하지 않습니다.
- 서버가 매 요청마다 KEY의 사번·권한·소유권을 검사합니다. MCP를 수정해도 서버 검사를 우회할 수 없습니다. 사용자가 이미 별도의 DB 접속 권한을 가진 경우까지 이 MCP가 제한하는 것은 아닙니다.
- 게시 초안은 서버에 파일과 함께 저장되지만 웹에서 본인이 승인하기 전에는 일반 목록에 게시되지 않습니다. 승인은 MCP 도구가 아니라 SSO 또는 mock 웹 세션에서 처리합니다. 게시하지 않으려면 승인하지 않고 두면 됩니다. 승인 후 내용을 바꿀 수 없고 새 초안을 만들어야 합니다.
- 다운로드는 웹과 같은 API를 사용하여 도구당 사번별 첫 다운로드만 집계합니다. 업데이트 수신은 집계하지 않습니다. 파일 수신과 실제 설치 완료는 별개입니다.
- 로컬 작업 폴더 허용 목록, ZIP 경로/링크/크기 검사와 단순 인증정보 패턴 검사를 수행합니다. 악성코드 검사나 임의 코드의 안전성 보증은 아닙니다.
- 자동 실행 프로그램이 사용자의 권한으로 작동한다는 점은 일반 설치기와 같습니다. 로컬 확인 단계는 사용 편의를 위한 절차이며, 수정한 로컬 프로그램을 신뢰 경계로 삼지 않습니다.

## 문제 해결

1. **401:** 이전 기간형 KEY의 만료·취소·재발급 또는 사용자 비활성화 등으로 인증할 수 없는 상태입니다. 안내된 현재 서버의 `/local-access` 링크를 확인하고 새 KEY가 필요하면 발급한 뒤 “AI SQUARE KEY 다시 연결해줘”라고 요청합니다. 계정 비활성화는 운영자에게 문의합니다.
2. **403:** 인증과 별개로 해당 도구 조회 권한, 업로드 포함 KEY인지, 본인 도구인지 확인합니다. KEY 재연결만으로 권한이 추가되지는 않습니다. 관리자 KEY도 남의 도구를 업데이트할 수 없습니다.
3. **409:** 웹 승인 전인지, 배포 버전이 변경되었는지 초안 상태를 확인합니다. 같은 KEY의 단순 통신 재시도는 같은 draft ID를 사용하면 중복 게시하지 않습니다. KEY를 재발급했다면 이전 초안을 이어 게시하지 말고 새 초안과 웹 승인을 진행합니다.
4. **허용 폴더 밖:** AI에게 원본/프로젝트 폴더 선택을 요청하고 열린 폴더 선택 창에서 직접 지정합니다. 고급 설정에서는 `--workspace`로 필요한 폴더만 추가할 수도 있습니다. MCP가 임의로 접근 범위를 늘리지 않습니다.
5. **서버 주소가 없다는 안내:** 웹의 **로컬 MCP 받기**에서 새 ZIP을 받으세요. 저장소의 공통 ZIP에는 운영 주소가 들어 있지 않습니다.
6. **Claude Connected만 표시됨:** “AI SQUARE 연결 상태 확인해줘” 또는 `python run_mcp.py status`로 본인 계정 인증까지 확인합니다.
7. **접속 실패 또는 5xx:** 사내망 연결·서버 상태를 확인합니다. 이것만으로 KEY가 만료되었다고 판단하거나 재발급하지 않습니다. 저장 요청이었다면 반영 여부부터 확인하고 다시 시도합니다.
